# Repository setup

## Инициализация локального репозитория

```shell
# Инициализировать репозиторий
git init

# Настроить пользователя (для текущего репозитория)
git config user.name "Username"
git config user.email "user@email.com"

# Добавить файлы и сделать первый коммит
echo "# Repo" >> README.md
git add README.md
git commit -m "Initial commit"

# Переименовать ветку в main
git branch -M main

# Добавить удаленный репозиторий
git remote add origin git@github.com:username/repo.git

# Отправить изменения и установить upstream
git push -u origin main
```

## Клонирование репозитория

```shell
# repo name folder
git clone git@github.com:username/repo.git

# another folder name
git clone git@github.com:username/repo.git local-dir-name
```

## Bare repo / local

Можно сделать репо на локальной машине и подключаться по ssh

1. Создать bare repo на машине условном сервере:
```shell
mkdir -p ~/git/my-project.git
cd ~/git/my-project.git
git init --bare
```

2. На машине-сервере можно работать с working copy в отдельной директории:
```shell
git clone ~/git/my-project.git ~/dev/my-project

git remote add origin git@github.com:username/repo.git
```

3. На другой машине можно склонировать репо по ssh:
```shell
git clone user@192.168.1.50:~/git/my-project.git
```
