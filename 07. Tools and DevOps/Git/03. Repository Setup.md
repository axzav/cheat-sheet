# Repository setup

## Инициализация локального репозитория

```shell
# Инициализировать репозиторий
git init

# Настроить пользователя (для текущего репозитория)
git config user.name "Username"
git config user.email "user@email.com"

# Добавить файлы и сделать первый коммит
echo "# Repo" >> README.md
git add README.md
git commit -m "Initial commit"

# Переименовать ветку в main
git branch -M main

# Добавить удаленный репозиторий
git remote add origin git@github.com:username/repo.git

# Отправить изменения и установить upstream
git push -u origin main
```

## Клонирование репозитория

```shell
# repo name folder
git clone git@github.com:username/repo.git

# another folder name
git clone git@github.com:username/repo.git new-repo-name
```
