Cherry-pick

Чтобы сделать cherry-pick коммита из другой ветки, вам нужно выполнить следующие шаги:

1. Убедитесь, что вы находитесь на ветке, куда хотите применить cherry-pick.

   bashCopy code

   `git checkout <branch-name>`

   где `<branch-name>` - это имя ветки, куда вы хотите применить cherry-pick.

2. Выполните команду `git cherry-pick <commit-hash>`, где `<commit-hash>` - это хеш коммита, который вы хотите перенести.

   bashCopy code

   `git cherry-pick <commit-hash>`

   Вы можете найти хеш коммита, используя `git log` в ветке, из которой хотите перенести коммит.

3. Если возникают конфликты, вам придется их разрешить вручную. После их разрешения, вы можете продолжить процесс cherry-pick, выполнив команду `git cherry-pick --continue`.

4. Если вам нужно отменить процесс cherry-pick (например, из-за сложного конфликта), вы можете использовать команду `git cherry-pick --abort`.


Обратите внимание, что cherry-pick создает новый коммит с теми же изменениями, что и оригинальный коммит. Это значит, что хеш коммита будет отличаться, даже если изменения в файлах идентичны.

---

Переписать последний коммит локально?

```shell
git commit --amend --no-edit --no-verify
```

---

Как удалить последний коммит в ветке git и запушить изменения с форсом в орижджин?

```bash
# Перемещаем HEAD на предыдущий коммит, не трогая рабочую область
git reset --hard HEAD~1

# Принудительно "пушим" изменения на сервер
git push origin +HEAD
```

---

Чтобы просмотреть все коммиты в ветке, начиная с момента её создания из другой ветки, вам нужно выполнить следующую команду в терминале, находясь внутри вашего репозитория:

git log <имя_стартовой_ветки>..<имя_вашей_ветки>
