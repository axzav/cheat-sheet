_# Git Authentication

Для аутентификации на удаленном сервере есть 2 способа — SSH и HTTPS.
Способ выбирается на основе протокола, указанного в `remote`:
```shell
git remote -v
```

```shell
SSH → git@github.com:username/repo.git
HTTPS → https://github.com/username/repo.git
```

## SSH

1. Сгенерировать пару ключей:
```shell
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github
```

2. Добавить публичный ключ в GitHub/GitLab

3. Добавить ключ в `~/.ssh/config`:
```shell
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github

# Other keys
Host gitlab.com
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_ed25519_gitlab
```

4. (Опционально) Если нужны разные ключи для одного хоста, то нужно использовать алиасы:
```shell
Host gitlab-work
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_gitlab_work

Host gitlab-personal
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_gitlab_personal
```

Remote будут выглядеть так:
```shell
git@gitlab-work:company/project1.git
git@gitlab-personal:personal/project2.git
```

## HTTPS

При первом пуше будет редирект/ссылка на гитхаб для аутентификации или надо будет ввести токен
Git сохраняет `Personal Access Token (PAT)` через **credential helper**

Проверить какой **credential helper** используется:
```shell
git config --global credential.helper
```
