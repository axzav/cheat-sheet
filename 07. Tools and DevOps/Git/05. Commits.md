# Коммиты

## Создание коммита

```shell
git add .
git commit -m "Описание коммита"
```

## Изменение последнего коммита

### Изменить сообщение коммита

Открыть редактор:

```shell
git commit --amend
```

Изменить сообщение без редактора:

```shell
git commit --amend -m "Новое сообщение коммита"
```

Добавить изменения в последний коммит (без изменения сообщения):

```shell
git commit --amend --no-edit --no-verify
```

### Отправка измененного коммита

Если коммит уже отправлен в удаленный репозиторий, потребуется force push:

```shell
git push --force
# или безопаснее
git push --force-with-lease
```

## Изменение не последнего коммита

Для изменения более ранних коммитов используется интерактивный rebase:

```shell
git rebase -i HEAD~<количество_коммитов>
```

В списке замените `pick` на `reword` для нужного коммита, сохранить и ввести новое сообщение.

## Удаление последнего коммита

Удалить последний коммит, сохранив изменения в рабочей директории:

```shell
git reset --soft HEAD~1
```

Удалить последний коммит и все изменения:

```shell
git reset --hard HEAD~1
```

После удаления локального коммита для синхронизации с удаленным репозиторием:

```shell
git push origin +HEAD
```
