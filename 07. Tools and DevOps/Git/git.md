# Git
Распределенная система контроля версий. Это значит, что каждая копия репозитория это не снимок файлов на какой-то момент, а полноценный бэкап всех данных.

Git появился в 2005 году, как альтернатива CKB BitKeeper. Создан разработчиками ядра линукс.

Файлы гит могут быть в 3х состояниях:
- `modified` - измененные файлы в рабочей директории. Еще не зафиксированны
- `staged` - файл, помеченный для включения в следующий коммит
- `commited` - файл сохранен в базе гит
