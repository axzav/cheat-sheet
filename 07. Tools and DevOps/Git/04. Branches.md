# Ветки в Git

Ветка — это указатель на коммит. Это не папка, не копия проекта, а просто указатель на последний коммит в цепочке. При создании нового коммита ветка "сдвигается" вперед.

**Просмотр веток:**
```shell
git branch --show-current # Показать текущую ветку
git branch # Показать локальные ветки
git branch -a # Показать локальные и удаленные ветки
git branch -r # Показать только удаленные ветки
git branch -vv # Показать связи с upstream
```

**Создание/переключение:**
```shell
git branch feat/login #Создать ветку без переключения

git checkout -b feat/login # Создать и сразу переключиться
git switch -c feat/login # Создать и сразу переключиться

git checkout branch-name  # Переключение между ветками
git switch branch-name    # Переключение между ветками
```

**Удаление веток:**
```shell
git branch -d feat/login # Удалить локальную ветку (только если она слита)
git branch -D feat/login # Принудительно удалить локальную ветку
```

**Работа с удаленными ветками:**
```shell
git push origin feat/login # Отправить ветку на удаленный репозиторий
git push -u origin feat/login # Отправить и установить upstream (связь с удаленной веткой)
```
**Upstream** — это связь между локальной и удаленной веткой. Позволяет синхронизироваться без указания полного пути.
После установки upstream можно использовать просто `git push` и `git pull`.


**Принудительная отправка изменений:**
```shell
git push origin HEAD --force
# или
git push origin HEAD --force-with-lease  # безопаснее
```

**Показать все коммиты в ветке, начиная с момента её создания из другой ветки:**
```shell
git log <имя_стартовой_ветки>..<имя_вашей_ветки>
```
