# Ветки в Git

## Что такое ветка

Ветка — это указатель на коммит. Это не папка, не копия проекта, а просто указатель на последний коммит в цепочке. При создании нового коммита ветка "сдвигается" вперед.

## Просмотр веток

Показать текущую ветку:

```shell
git branch --show-current
```

Показать локальные ветки:

```shell
git branch
```

Показать локальные и удаленные ветки:

```shell
git branch -a
```

Показать только удаленные ветки:

```shell
git branch -r
```

Показать связи с upstream:

```shell
git branch -vv
```

## Создание веток

Создать ветку без переключения:

```shell
git branch feat/login
```

Создать и сразу переключиться:

```shell
git checkout -b feat/login
# или
git switch -c feat/login
```

## Переключение между ветками

```shell
git checkout branch-name
# или
git switch branch-name
```

## Удаление веток

Удалить локальную ветку (только если она слита):

```shell
git branch -d feat/login
```

Принудительно удалить локальную ветку:

```shell
git branch -D feat/login
```

## Работа с удаленными ветками

Отправить ветку на удаленный репозиторий:

```shell
git push origin feat/login
```

Отправить и установить upstream (связь с удаленной веткой):

```shell
git push -u origin feat/login
```

После установки upstream можно использовать просто `git push` и `git pull`.

### Что такое upstream

Upstream — это связь между локальной и удаленной веткой. Позволяет синхронизироваться без указания полного пути.

### Force push

Принудительная отправка изменений:

```shell
git push origin HEAD --force
# или
git push origin HEAD --force-with-lease  # безопаснее
```

## Просмотр коммитов в ветке

Показать все коммиты в ветке, начиная с момента её создания из другой ветки:

```shell
git log <имя_стартовой_ветки>..<имя_вашей_ветки>
```
