Чтобы изменить описание (message) уже созданного коммита в Git, можно воспользоваться командой:

```bash
git commit --amend
```

### Пошаговая инструкция:

1. **Убедитесь, что вы находитесь в нужной ветке.**

   ```bash
   git checkout <branch_name>
   ```

2. **Откройте описание последнего коммита для редактирования.**

   ```bash
   git commit --amend
   ```

   Эта команда откроет ваш текстовый редактор (например, `vim`, `nano` или другой, указанный в настройках Git). В редакторе отобразится текущее сообщение последнего коммита.

3. **Измените текст описания.**
   Внесите необходимые изменения в текст коммита, сохраните и закройте редактор.

4. **Обновите коммит в репозитории.**
   После сохранения изменений Git обновит последний коммит с новым описанием.

---

### Примечания:

* **Если коммит уже отправлен в удалённый репозиторий,** изменения нужно будет форсировать:

  ```bash
  git push --force
  ```

  ⚠️ Используйте форсированную отправку с осторожностью, так как это может привести к конфликтам у других участников команды.

* **Если вам нужно изменить описание не последнего коммита,** используйте **`git rebase`**. Например:

  ```bash
  git rebase -i HEAD~<количество последних коммитов>
  ```

  В появившемся списке найдите нужный коммит, замените `pick` на `reword`, сохраните изменения и введите новое сообщение для этого коммита.

---

можно как-то без редактора чтобы в командной строке просто ввести новый месседж коммита?

---

Да, можно изменить сообщение коммита без открытия текстового редактора, прямо в командной строке. Для этого используйте флаг `-m` с командой `git commit --amend`, указав новое сообщение коммита:

```bash
git commit --amend -m "Новое сообщение для коммита"
```

### Пример:

```bash
git commit --amend -m "Исправлено описание и обновлены данные"
```

Это обновит сообщение последнего коммита без необходимости открывать редактор.

---

### Примечания:

* Если коммит уже отправлен в удалённый репозиторий, не забудьте выполнить форсированный push:

  ```bash
  git push --force
  ```
