# Аутентификация в Git

Для аутентификации на удаленном сервере есть два способа: **SSH** и **HTTPS**. Способ выбирается на основе протокола, указанного в `remote`:

```shell
# SSH
git@github.com:username/repo.git

# HTTPS
https://github.com/username/repo.git
```

## SSH

### 1. Генерация пары ключей

```shell
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github
```

### 2. Добавление публичного ключа

Добавить публичный ключ в GitHub/GitLab через настройки аккаунта.

### 3. Настройка SSH config

Добавить ключ в `~/.ssh/config`:

```shell
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github

Host gitlab.com
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_ed25519_gitlab
```

### 4. Разные ключи для одного хоста

Если нужны разные ключи для одного хоста, можно использовать алиасы:

```shell
Host gitlab-work
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_gitlab_work

Host gitlab-personal
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_gitlab_personal
```

Remote будут выглядеть так:

```shell
git@gitlab-work:company/project1.git
git@gitlab-personal:personal/project2.git
```

## HTTPS

При первом push будет редирект на GitHub для аутентификации или потребуется ввести токен. Git сохраняет `Personal Access Token (PAT)` через **credential helper**.

Проверить, какой credential helper используется:

```shell
git config --global credential.helper
```
