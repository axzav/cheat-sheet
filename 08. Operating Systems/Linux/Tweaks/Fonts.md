# Настройка шрифтов в Linux

---
`GSettings`, `XSettings`, `Fontconfig` - как связаны?
Какие есть настройки для шрифтов в GSettings? Только Hinting и Antialiasing?
---

## Уровни рендеринга

### Уровень 1: FreeType и Fontconfig

**FreeType** — это движок, который превращает векторные контуры шрифта в пиксели.

**Fontconfig** это система управления шрифтами Linux, централизованная база правил.
Она решает:
* какой шрифт выбрать для определенного семейства
* какие fallback использовать
* какие настройки рендеринга применить

Если приложение не знает, какой именно шрифт использовать это решает **Fontconfig**.
Fontconfig делает примерно такое соответствие:
```
sans-serif → Noto Sans
monospace → DejaVu Sans Mono
serif → Noto Serif
```

Конкретные приложения запрашивают данные настроек для конкретных шрифтов у Fontconfig.


### Уровень 2: Тулкиты (GTK и Qt)

Приложения пишутся на разных библиотеках. Ubuntu использует `GTK`. Это встроенные стандартные приложения - Наутилус, Текстовый редактор, Панель GNOME.

Приложения `GTK` слушают настройки из `XSettings`.
`GNOME` берет настройки из `GSettings` и транслирует их в `XSettings`.

Qt-приложения (например, VLC или софт из KDE) могут игнорировать настройки GTK, и для них иногда нужно ставить qt6ct или kvantum.


### Уровень 3: Специфические движки (Chrome, Java, Electron)

**Браузеры (Chrome/Brave)**: Используют движок Skia. На Linux Skia использует FreeType для растеризации.
Они сначала смотрят на `XSettings` (чтобы соответствовать теме оформления), но параметры самой отрисовки (какой фильтр использовать, как сглаживать) они часто берут напрямую из `Fontconfig` через библиотеку `FreeType`.
Если в Chrome включено аппаратное ускорение, он может игнорировать часть системных правил, используя свои алгоритмы сглаживания.

**VSCode (Electron)**: Это по сути тот же Chrome.

**PHPStorm (JBR)**: Внутри Java-машины сидит свой код для работы со шрифтами. Он может либо вызывать системную библиотеку FreeType, либо использовать встроенную (bundled). 
Но даже используя FreeType, Java часто игнорирует тонкие настройки из fonts.conf, если они не прописаны через параметры запуска (VM Options).
Java также смотрит в настройки `XSettings`.
Параметры запуска (VM Options): Если там прописано `-Dawt.useSystemAAFontSettings`, Java пойдет смотреть системные настройки.


### Настройка шрифтов на разных уровнях

**Шаг 1: Fontconfig Мастер-конфиг**

Создать и настроить `~/.config/fontconfig/fonts.conf`

**Шаг 2: Синхронизация GNOME**

В GSettings выставить те же параметры, что и в `Fontconfig`.

**Шаг 3: Проверить XSettings**

Проверить что настройки XSettings совпадают с предыдущими уровнями:
```shell
xrdb -query | grep Xft
```

**Шаг 4: Настройки параметров запуска в приложениях**

Для `chrome/electron based` приложений проверить и поменять при необходимости параметры запуска, например:
```text
--font-antialiasing=grayscale
```

Для `Java` приложений проверить и поменять при необходимости параметры VM Options, например:
```text
-Dawt.useSystemAAFontSettings=on
-Dsun.java2d.font.disableFontConfig=false
```

**Шаг 5: Настройки шрифтов в приложениях**

Отрегулировать настройки, доступные в самих приложениях непосредственно.


## Классы шрифтов

**font-family** — это CSS/GUI-понятие, которое обозначает имя семейства шрифтов, запрашиваемое приложением.

```css
font-family: sans-serif;
```


### Serif
Шрифты с засечками, используются в книгах. Например:
* Times
* Georgia

### Sans-serif
Sans = без. Шрифты без засечек, они лучше для экранов. Например:
Примеры:
* Inter
* Roboto
* Noto Sans

### Monospace / Fixed-width

Каждый символ одинаковой ширины. Используется для программирования и терминалов. Например:
* JetBrains Mono
* Fira Code
* DejaVu Sans Mono


## Установка шрифтов

Самые популярные шрифты:

**UI / системные:**
* Inter
* Noto Sans
* Roboto

**Для кода:**
* JetBrains Mono
* Fira Code


```shell
sudo apt install fonts-inter fonts-jetbrains-mono fonts-firacode fonts-noto
```
После установки шрифты появятся в `/usr/share/fonts` и будут доступны в системе и приложениях.
