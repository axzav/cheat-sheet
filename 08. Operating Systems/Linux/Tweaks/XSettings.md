# XSettings

Это специальный протокол, который позволяет Desktop Environment (GNOME, KDE, XFCE) передавать настройки запущенным приложениям в реальном времени.

Там передаются:
* Текущая GTK-тема (Dark/Light).
* Набор иконок.
* Параметры Xft: DPI, хинтинг, сглаживание.

```shell
xrdb -query | grep Xft
```
