# AppImage

**AppImage** — это один исполняемый файл программы. Программа содержит всё внутри, никакой установки. Похоже на portable exe в Windows.

```shell
chmod +x program.AppImage
./program.AppImage
```

Плюсы:
* не требует установки
* работает на разных дистрибутивах
* не ломает систему

Минусы:
* обновления вручную
* не интегрируется в систему
* зависимости внутри файла
