# APT

**APT** — это пакетный менеджер для систем на базе Debian.
Он устанавливает `.deb` пакеты из репозиториев системы.

Процесс установки:
* `.deb` пакет скачивается из репозитория
* автоматически вычисляет все зависимости
* вызывает `dpkg` для установки `.deb`

Плюсы:
* Нативный, полностью интегрирован в систему
* Автоматические обновления
* Автоматически разрешаются зависимости
* Легко удалять

Минусы:
* Часто старые версии приложений
* Не все приложения есть в репозитории

```shell
sudo apt install nginx
sudo apt install ./program.deb
sudo dpkg -i program.deb    # не рекомендуется, dpkg не умеет работать с зависимостями

sudo apt remove nginx   # оставляет конфиги
sudo apt purge nginx    # полное удаление
sudo apt autoremove     # удаляет неиспользуемые зависимости

apt list --installed    # список установленных пакетов
apt search nginx        # поиск пакетов
apt show nginx          # информация о пакете
apt depends nginx       # зависимости пакета
apt rdepends nginx      # кто зависит от пакета

dpkg -l                 # список установленных пакетов 
dpkg -L nginx           # посмотреть список файлов установленного пакета
dpkg -S /usr/bin/nginx  # какой пакет владеет файлом

apt clean               # очисть кэш /var/cache/apt/archives
apt autoclean           # удаляет только устаревшие пакеты

sudo apt update
sudo apt upgrade        # обновляет пакеты без удаления зависимостей
```

## Репозитории

APT работает с **репозиториями пакетов**.

```shell
/etc/apt/sources.list.d/ubuntu.sources
/etc/apt/sources.list.d/
```

Можно добавить пользовательские репозитории:
```shell
add-apt-repository ppa:ondrej/php
apt update
```

## DEB (пакет Debian)

`.deb` — это архив с метаданными и файлами программы. Формально это **ar архив**, внутри:
```text
package.deb
 ├── debian-binary
 ├── control.tar.gz
 └── data.tar.gz
```

* **debian-binary** - Версия формата
* **control.tar.gz** - Метаданные пакета

```text
control
postinst
prerm
postrm
conffiles
```

Пример `control`:

```
Package: nginx
Version: 1.24.0
Architecture: amd64
Depends: libc6, libssl3
Maintainer: Debian Nginx Maintainers
Description: high performance web server
```

* **data.tar.gz** -Файлы программы

```text
usr/bin/nginx
usr/share/doc/nginx
etc/nginx/nginx.conf
lib/systemd/system/nginx.service
```

Debian следует стандарту **FHS (Filesystem Hierarchy Standard)**.

Типичное распределение:

| тип                 | путь                  |
| ------------------- | --------------------- |
| бинарники           | `/usr/bin`            |
| системные бинарники | `/usr/sbin`           |
| библиотеки          | `/usr/lib`            |
| конфиги             | `/etc`                |
| документация        | `/usr/share/doc`      |
| systemd сервисы     | `/lib/systemd/system` |
| shared data         | `/usr/share`          |

При установке `dpkg` **распаковывает файлы в root filesystem `/`**.

Все пакеты регистрируются в `/var/lib/dpkg/`.
Основные файлы:
```text
/var/lib/dpkg/status
/var/lib/dpkg/info/
/var/lib/dpkg/info/nginx.list   # список всех файлов пакета
/var/lib/dpkg/info/nginx.postinst
/var/lib/dpkg/info/nginx.prerm
```
