# Snap

**Snap** — пакетная система от Canonical (Ubuntu).
Snap — это контейнеризированные приложения.

```shell
sudo snap install code
sudo snap remove code
sudo snap refresh
```

Snap хранит пакеты в `/snap`

Как работает:
* приложение упаковано вместе с зависимостями
* работает в sandbox

Плюсы:
* всегда свежие версии
* работает на разных дистрибутивах
* обновляется автоматически
* легко ставить

Минусы:
* медленный запуск
* большой размер
* иногда плохая интеграция с системой, проблемы с темами UI
* закрытая инфраструктура Canonical

При возможности лучше использовать `Flatpak`
