# Flatpak

**Flatpak** — альтернатива Snap, разработанная сообществом Linux.
Более популярный, чем Snap.
Самый популярный репозиторий - https://flathub.org/en

```shell
sudo apt install flatpak  # установить менеджер в систему
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo # установить репо flathub

flatpak list # посмотреть установленные
flatpak update # обновить приложения

flatpak install flathub org.telegram.desktop
flatpak update
flatpak uninstall org.telegram.desktop
```

Как работает:
* Flatpak использует runtime — общие библиотеки
* работает в sandbox
* приложение с зависимостями


Плюсы:
* всегда свежие версии
* работает на разных дистрибутивах
* обновляется автоматически
* легко ставить

Минусы:
* большой размер
* иногда плохая интеграция с системой, проблемы с темами UI
