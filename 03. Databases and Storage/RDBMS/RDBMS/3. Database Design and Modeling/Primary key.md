# Primary Key

Primary key (первичный ключ) — уникальный идентификатор записи в таблице базы данных. Обеспечивает уникальность каждой записи и позволяет однозначно идентифицировать каждую строку в таблице.

## Основные характеристики

### Уникальность
Значение primary key должно быть уникальным для каждой записи в таблице. Это гарантирует, что не будет двух записей с одинаковым значением первичного ключа.

### Неизменность
Значение primary key не должно изменяться после того, как оно было установлено. Это позволяет поддерживать целостность данных и их связей.

### Отсутствие NULL
Поле, выбранное в качестве primary key, не должно содержать NULL значений. Каждая запись должна иметь определенное значение ключа.

## Создание Primary Key

```sql
-- MySQL
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL
);

-- PostgreSQL
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL
);
```

В этом примере поле `id` является primary key. Оно автоматически увеличивается для каждой новой записи.

## Составной Primary Key

Иногда для уникальной идентификации записи требуется несколько полей. В этом случае используется составной primary key (composite primary key).

```sql
CREATE TABLE order_items (
    order_id INT,
    product_id INT,
    quantity INT,
    PRIMARY KEY (order_id, product_id)
);
```

Комбинация полей `order_id` и `product_id` уникально идентифицирует каждую запись в таблице, обеспечивая, что для каждого заказа и продукта существует только одна запись.

## Преимущества

1. **Целостность данных**: Гарантирует уникальность каждой записи и предотвращает дублирование данных
2. **Производительность**: Ускоряет поиск, обновление и удаление записей, так как индексируется автоматически
3. **Связи между таблицами**: Обеспечивает установление и поддержание связей между таблицами через foreign keys

## Сравнение с другими типами ключей

- **Primary Key**: Уникальный, не может быть NULL, только один на таблицу
- **Unique Key**: Уникальный, может быть NULL, может быть несколько на таблицу
- **Foreign Key**: Ссылается на primary key другой таблицы
