# Relational databases and their principles

Реляционные базы данных это такой тип системы управления базами данных (database management system, DBMS), которая хранит данные в виде таблиц со связями между ними.

Основные принципы и элементы реляционных баз данных:

**Tables** - все данные хранятся в таблицах. Колонки в таблице обозначают поля сущности, строка таблицы - конкретная сущность

**Keys** - ключи позволяют идентифицировать данные в таблицах. Ключи бывают разных типов - primary key, foreign key, unique keys. Первичный ключ служит для идентификации конкретной сущности в базе, внешний ключ (ссылается на первичный ключ другой сущности) служит для построения связей между сущностями

**Normalization** - процесс разбиения данных на небольшие таблицы, который служит для уменьшения объема хранимых данных и обеспечивает целостность данных. Уровень нормализации данных описывается используемой нормальной формой - (1NF, 2NF, 3NF, BCNF)

**Integrity Constraints** - базы данных обеспечивают целостность данных с помощью ограничений целостности. Они делятся на 3 основных типа: целостность сущности (первичный ключ не может быть NULL), ссылочная целостность (внешний ключ может ссылаться только на первичный ключ другой сущности), доменная целостность (ограничения, пораждаемые бизнес логикой - уникальный email, строгий набор значений для конкртеных полей и тд)

**SQL** - язык SQL является стандартом для реляционных баз данных. Этот язык предоставляет возможности для работы с данными в базе, работы со схемой данных и администрирования базы
