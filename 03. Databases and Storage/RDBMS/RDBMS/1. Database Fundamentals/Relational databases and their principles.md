# Реляционные базы данных и их принципы

Реляционные базы данных — тип системы управления базами данных (Database Management System, DBMS), который хранит данные в виде таблиц со связями между ними.

## Основные принципы и элементы

### Tables (Таблицы)

Все данные хранятся в таблицах. Колонки в таблице обозначают поля сущности (атрибуты), строка таблицы представляет конкретную сущность (запись, кортеж).

### Keys (Ключи)

Ключи позволяют идентифицировать данные в таблицах. Основные типы:

- **Primary Key** (первичный ключ) — уникальный идентификатор записи в таблице. Не может быть NULL и должен быть уникальным
- **Foreign Key** (внешний ключ) — ссылается на первичный ключ другой таблицы, обеспечивает связь между таблицами
- **Unique Key** (уникальный ключ) — обеспечивает уникальность значений в столбце, но не является первичным ключом
- **Composite Key** (составной ключ) — ключ, состоящий из нескольких столбцов

### Normalization (Нормализация)

Процесс разбиения данных на небольшие таблицы для уменьшения избыточности данных и обеспечения целостности. Уровни нормализации:

- **1NF (First Normal Form)** — каждая ячейка содержит атомарное значение, нет повторяющихся групп
- **2NF (Second Normal Form)** — находится в 1NF, все неключевые атрибуты полностью зависят от первичного ключа
- **3NF (Third Normal Form)** — находится в 2NF, нет транзитивных зависимостей (неключевые атрибуты не зависят от других неключевых атрибутов)
- **BCNF (Boyce-Codd Normal Form)** — усиленная версия 3NF, каждая детерминанта является потенциальным ключом

### Integrity Constraints (Ограничения целостности)

Базы данных обеспечивают целостность данных с помощью ограничений. Основные типы:

- **Entity Integrity** (целостность сущности) — первичный ключ не может быть NULL, каждая запись должна быть уникально идентифицируема
- **Referential Integrity** (ссылочная целостность) — внешний ключ может ссылаться только на существующий первичный ключ другой таблицы
- **Domain Integrity** (доменная целостность) — ограничения на значения данных (CHECK constraints, NOT NULL, UNIQUE, типы данных)
