# Агрегация и группировка

Агрегатные функции выполняют вычисления над набором значений и возвращают единственный результат. Используются для анализа и обобщения информации из множества записей.

## Основные агрегатные функции

### COUNT()

Подсчитывает количество элементов в наборе:

```sql
-- Количество всех строк
SELECT COUNT(*) FROM users;

-- Количество не-NULL значений в столбце
SELECT COUNT(email) FROM users;

-- Количество уникальных значений
SELECT COUNT(DISTINCT city) FROM users;
```

### SUM()

Суммирует числовые значения столбца:

```sql
SELECT SUM(salary) FROM employees;

-- С условием
SELECT SUM(amount) FROM orders WHERE status = 'completed';
```

### AVG()

Вычисляет среднее арифметическое значение:

```sql
SELECT AVG(price) FROM products;

-- Округление результата
SELECT ROUND(AVG(price), 2) AS avg_price FROM products;
```

### MIN() и MAX()

Возвращают минимальное и максимальное значения:

```sql
SELECT MIN(age), MAX(age) FROM users;

SELECT MIN(order_date), MAX(order_date) FROM orders;
```

### Строковая агрегация

Объединение строк из столбца в одну строку с разделителем:

```sql
-- PostgreSQL
SELECT STRING_AGG(username, ', ' ORDER BY username) 
FROM users 
WHERE city = 'Moscow';

-- MySQL
SELECT GROUP_CONCAT(username SEPARATOR ', ' ORDER BY username)
FROM users 
WHERE city = 'Moscow';
```

## GROUP BY

Группирует строки по одному или нескольким столбцам и применяет агрегатные функции к каждой группе:

```sql
-- Группировка по одному столбцу
SELECT department, AVG(salary) AS average_salary
FROM employees
GROUP BY department;

-- Группировка по нескольким столбцам
SELECT country, city, COUNT(*) AS user_count
FROM users
GROUP BY country, city;

-- Группировка с несколькими агрегатами
SELECT 
    department,
    COUNT(*) AS employee_count,
    AVG(salary) AS avg_salary,
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary
FROM employees
GROUP BY department;
```

## HAVING

Фильтрует группы после применения `GROUP BY`. В отличие от `WHERE`, может использовать агрегатные функции:

```sql
SELECT department, COUNT(*) AS num_employees
FROM employees
GROUP BY department
HAVING COUNT(*) > 10;

-- Сравнение агрегатов
SELECT 
    department,
    AVG(salary) AS avg_salary
FROM employees
GROUP BY department
HAVING AVG(salary) > 50000;
```

## WHERE vs HAVING

### WHERE

- Фильтрует строки **до** группировки
- Не может использовать агрегатные функции
- Применяется к отдельным записям

```sql
SELECT department, AVG(salary)
FROM employees
WHERE salary > 30000  -- фильтрация до группировки
GROUP BY department;
```

### HAVING

- Фильтрует группы **после** группировки
- Может использовать агрегатные функции
- Применяется к группам

```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department
HAVING AVG(salary) > 50000  -- фильтрация после группировки
```

### Использование вместе

```sql
SELECT 
    department,
    COUNT(*) AS employee_count,
    AVG(salary) AS avg_salary
FROM employees
WHERE hire_date > '2020-01-01'  -- фильтрация строк
GROUP BY department
HAVING COUNT(*) > 5  -- фильтрация групп
ORDER BY avg_salary DESC;
```

## Порядок выполнения

1. `FROM` — выбор таблиц
2. `WHERE` — фильтрация строк
3. `GROUP BY` — группировка
4. Агрегатные функции — вычисление агрегатов
5. `HAVING` — фильтрация групп
6. `SELECT` — выбор столбцов
7. `ORDER BY` — сортировка
8. `LIMIT` — ограничение результата

## GROUPING SETS, ROLLUP, CUBE

Расширенные возможности группировки для получения множественных уровней агрегации:

### ROLLUP

Создает иерархию групп:

```sql
SELECT 
    country,
    city,
    SUM(sales) AS total_sales
FROM sales_data
GROUP BY ROLLUP(country, city);
-- Результат: группы по (country, city), по (country), общий итог
```

### CUBE

Создает все возможные комбинации групп:

```sql
SELECT 
    year,
    quarter,
    product_category,
    SUM(sales) AS total_sales
FROM sales_data
GROUP BY CUBE(year, quarter, product_category);
```

### GROUPING SETS

Явное указание наборов для группировки:

```sql
SELECT 
    country,
    city,
    SUM(sales) AS total_sales
FROM sales_data
GROUP BY GROUPING SETS (
    (country, city),
    (country),
    ()
);
```

## Примеры использования

### Статистика по группам

```sql
SELECT 
    category,
    COUNT(*) AS product_count,
    AVG(price) AS avg_price,
    MIN(price) AS min_price,
    MAX(price) AS max_price,
    SUM(stock) AS total_stock
FROM products
GROUP BY category
ORDER BY avg_price DESC;
```

### Топ-N по группам

```sql
SELECT 
    department,
    employee_name,
    salary
FROM (
    SELECT 
        department,
        employee_name,
        salary,
        RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS rnk
    FROM employees
) ranked
WHERE rnk <= 3;
```

### Фильтрация по агрегатам

```sql
-- Отделы с более чем 5 сотрудниками и средней зарплатой > 50000
SELECT 
    department,
    COUNT(*) AS employee_count,
    AVG(salary) AS avg_salary
FROM employees
GROUP BY department
HAVING COUNT(*) > 5 AND AVG(salary) > 50000;
```
