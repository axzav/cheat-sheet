# Оконные функции (Window Functions)

Агрегационные функции схлопывают результат в одну строку по группе. Оконные функции позволяют сохранять все строки, работая с выделенным набором строк (партиция, окно, фрейм).

## Основные отличия

- **Агрегатные функции** — группируют данные и возвращают одно значение на группу
- **Оконные функции** — сохраняют все строки, но вычисляют значения на основе окна строк

## Синтаксис

### Вызов оконной функции

```sql
function_name([expression [, expression ...]]) 
[FILTER (WHERE filter_clause)] 
OVER window_name

-- или

function_name([expression [, expression ...]]) 
[FILTER (WHERE filter_clause)] 
OVER (window_definition)
```

### Определение окна

```sql
[existing_window_name]
[PARTITION BY expression [, ...]]
[ORDER BY expression [ASC | DESC | USING operator] [NULLS {FIRST | LAST}] [, ...]]
[frame_clause]
```

### Inline определение в SELECT

```sql
SELECT city, month, 
    SUM(sold) OVER (
        PARTITION BY city 
        ORDER BY month 
        RANGE UNBOUNDED PRECEDING
    ) AS total
FROM sales;
```

### Именованное определение окна

Если нужно использовать одно и то же окно несколько раз, его можно определить в конце запроса:

```sql
SELECT country, city,
    RANK() OVER country_sold_avg,
    DENSE_RANK() OVER country_sold_avg
FROM sales
WHERE month BETWEEN 1 AND 6
GROUP BY country, city
HAVING SUM(sold) > 10000
WINDOW country_sold_avg AS (
    PARTITION BY country 
    ORDER BY AVG(sold) DESC
)
ORDER BY country, city;
```

## Партицирование (PARTITION BY)

Партицирование разделяет данные на группы, внутри которых выполняются вычисления. Можно партицировать по одному или нескольким столбцам:

```sql
-- Партицирование по одному столбцу
SELECT 
    department,
    employee_name,
    salary,
    AVG(salary) OVER (PARTITION BY department) AS avg_dept_salary
FROM employees;

-- Партицирование по нескольким столбцам
SELECT 
    country,
    city,
    sales,
    SUM(sales) OVER (PARTITION BY country, city) AS city_total
FROM sales_data;
```

## Порядок выполнения

Оконные функции выполняются после группировки (`GROUP BY`) и агрегационных функций, но перед сортировкой (`ORDER BY`) и ограничением (`LIMIT`).

## Классы оконных функций

### Агрегирующие функции

Используются как оконные функции для вычисления агрегатов без группировки:

```sql
SELECT 
    product_id,
    sale_date,
    amount,
    SUM(amount) OVER (PARTITION BY product_id ORDER BY sale_date) AS running_total,
    AVG(amount) OVER (PARTITION BY product_id) AS avg_amount,
    COUNT(*) OVER (PARTITION BY product_id) AS total_sales
FROM sales;
```

Основные функции: `SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()`, `STRING_AGG()`

### Ранжирующие функции

Присваивают ранг строкам в партиции:

```sql
SELECT 
    employee_name,
    salary,
    RANK() OVER (ORDER BY salary DESC) AS salary_rank,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS dense_rank,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num,
    PERCENT_RANK() OVER (ORDER BY salary DESC) AS percent_rank
FROM employees;
```

- `RANK()` — ранг с пропусками при одинаковых значениях
- `DENSE_RANK()` — ранг без пропусков
- `ROW_NUMBER()` — порядковый номер строки
- `PERCENT_RANK()` — процентный ранг (0.0 до 1.0)

### Функция NTILE

Делит партицию на равные части:

```sql
SELECT 
    student_name,
    score,
    NTILE(4) OVER (ORDER BY score DESC) AS quartile
FROM exam_results;
```

### Функции смещения

Получают значения из других строк:

```sql
SELECT 
    date,
    sales,
    LAG(sales, 1) OVER (ORDER BY date) AS prev_sales,
    LEAD(sales, 1) OVER (ORDER BY date) AS next_sales,
    FIRST_VALUE(sales) OVER (PARTITION BY month ORDER BY date) AS first_in_month,
    LAST_VALUE(sales) OVER (PARTITION BY month ORDER BY date ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS last_in_month
FROM daily_sales;
```

- `LAG(column, n)` — значение из предыдущей строки
- `LEAD(column, n)` — значение из следующей строки
- `FIRST_VALUE(column)` — первое значение в окне
- `LAST_VALUE(column)` — последнее значение в окне

### Функции распределения

```sql
SELECT 
    student_name,
    score,
    CUME_DIST() OVER (ORDER BY score) AS cumulative_distribution
FROM exam_results;
```

- `CUME_DIST()` — кумулятивное распределение (доля строк со значением <= текущего)

## Фреймы (Frame Clauses)

Определяют набор строк в партиции для вычисления:

```sql
-- Текущая строка и все предыдущие
SUM(amount) OVER (ORDER BY date ROWS UNBOUNDED PRECEDING)

-- Текущая строка и 2 предыдущие
AVG(amount) OVER (ORDER BY date ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)

-- Текущая строка, предыдущая и следующая
SUM(amount) OVER (ORDER BY date ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING)

-- Все строки в партиции
SUM(amount) OVER (PARTITION BY department ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
```

## Важные замечания

- Нельзя использовать результат оконной функции в `WHERE` — для фильтрации использовать подзапрос или CTE
- Оконные функции нельзя использовать внутри других оконных функций напрямую
- `PARTITION BY` можно использовать с несколькими полями: `PARTITION BY field1, field2`
