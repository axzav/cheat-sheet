# Triggers

Triggers are database objects that automatically execute in response to specific events (INSERT, UPDATE, DELETE) on a table.

## Creating Triggers

### PostgreSQL
```sql
CREATE TRIGGER trigger_name
    BEFORE | AFTER | INSTEAD OF
    INSERT | UPDATE | DELETE
    ON table_name
    FOR EACH ROW | FOR EACH STATEMENT
    EXECUTE FUNCTION function_name();
```

### MySQL
```sql
CREATE TRIGGER trigger_name
    BEFORE | AFTER
    INSERT | UPDATE | DELETE
    ON table_name
    FOR EACH ROW
    BEGIN
        -- trigger body
    END;
```

## Example: Audit Log

### PostgreSQL
```sql
CREATE OR REPLACE FUNCTION audit_log()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO audit_table (table_name, action, timestamp)
    VALUES (TG_TABLE_NAME, TG_OP, NOW());
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER users_audit
    AFTER INSERT OR UPDATE OR DELETE
    ON users
    FOR EACH ROW
    EXECUTE FUNCTION audit_log();
```

### MySQL
```sql
CREATE TRIGGER users_audit
AFTER INSERT ON users
FOR EACH ROW
BEGIN
    INSERT INTO audit_table (table_name, action, timestamp)
    VALUES ('users', 'INSERT', NOW());
END;
```

## Trigger Timing

- **BEFORE**: Executes before the event
- **AFTER**: Executes after the event
- **INSTEAD OF**: Replaces the event (PostgreSQL, for views)

## Trigger Scope

- **FOR EACH ROW**: Executes once per row affected
- **FOR EACH STATEMENT**: Executes once per statement (PostgreSQL)

## Accessing Row Data

### PostgreSQL
- `NEW`: New row (INSERT, UPDATE)
- `OLD`: Old row (UPDATE, DELETE)

### MySQL
- `NEW.column_name`: New row values
- `OLD.column_name`: Old row values

## Dropping Triggers

```sql
DROP TRIGGER trigger_name ON table_name;  -- PostgreSQL
DROP TRIGGER trigger_name;                 -- MySQL
```

## Use Cases

1. **Audit Logging**: Track changes to data
2. **Data Validation**: Enforce business rules
3. **Automatic Calculations**: Update related tables
4. **Change Notifications**: Notify other systems

## Best Practices

- Keep triggers simple and fast
- Avoid recursive triggers
- Document trigger logic
- Consider performance impact
- Use sparingly - prefer application logic when possible
