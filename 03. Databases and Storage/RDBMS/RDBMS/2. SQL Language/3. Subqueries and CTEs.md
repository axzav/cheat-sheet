# Подзапросы и CTE

Подзапросы (Subqueries) и Common Table Expressions (CTE) позволяют структурировать сложные запросы и улучшать их читаемость.

## Подзапросы (Subqueries)

Подзапрос — это SQL-запрос, вложенный в другой запрос. Может использоваться в различных частях основного запроса.

### Подзапросы в WHERE

```sql
-- Найти пользователей старше среднего возраста
SELECT username, age
FROM users
WHERE age > (SELECT AVG(age) FROM users);

-- Найти заказы пользователей из Москвы
SELECT *
FROM orders
WHERE user_id IN (
    SELECT id FROM users WHERE city = 'Moscow'
);
```

### Подзапросы в SELECT

```sql
-- Добавить количество заказов для каждого пользователя
SELECT 
    username,
    (SELECT COUNT(*) FROM orders WHERE user_id = users.id) AS order_count
FROM users;
```

### Подзапросы в FROM

```sql
-- Использование подзапроса как таблицы
SELECT subquery.username, subquery.total
FROM (
    SELECT u.id, u.username, SUM(o.total) AS total
    FROM users u
    JOIN orders o ON u.id = o.user_id
    GROUP BY u.id, u.username
) AS subquery
WHERE subquery.total > 1000;
```

### Коррелированные подзапросы

Подзапрос, который ссылается на столбцы внешнего запроса:

```sql
-- Для каждого пользователя найти последний заказ
SELECT 
    u.username,
    (SELECT order_date 
     FROM orders 
     WHERE user_id = u.id 
     ORDER BY order_date DESC 
     LIMIT 1) AS last_order_date
FROM users u;
```

### EXISTS и NOT EXISTS

Проверка существования записей:

```sql
-- Пользователи, у которых есть заказы
SELECT *
FROM users u
WHERE EXISTS (
    SELECT 1 FROM orders o WHERE o.user_id = u.id
);

-- Пользователи без заказов
SELECT *
FROM users u
WHERE NOT EXISTS (
    SELECT 1 FROM orders o WHERE o.user_id = u.id
);
```

## Common Table Expressions (CTE)

CTE — именованный временный результат запроса, который можно использовать в основном запросе. Улучшает читаемость сложных запросов.

### Базовый синтаксис

```sql
WITH cte_name AS (
    SELECT ...
)
SELECT * FROM cte_name;
```

### Простой пример

```sql
WITH active_users AS (
    SELECT id, username, email
    FROM users
    WHERE status = 'active'
)
SELECT au.username, COUNT(o.id) AS order_count
FROM active_users au
LEFT JOIN orders o ON au.id = o.user_id
GROUP BY au.id, au.username;
```

### Множественные CTE

Можно определить несколько CTE в одном запросе:

```sql
WITH 
    user_stats AS (
        SELECT user_id, COUNT(*) AS order_count, SUM(total) AS total_spent
        FROM orders
        GROUP BY user_id
    ),
    top_users AS (
        SELECT user_id, total_spent
        FROM user_stats
        WHERE total_spent > 1000
    )
SELECT u.username, tu.total_spent
FROM top_users tu
JOIN users u ON tu.user_id = u.id;
```

### CTE в UPDATE и DELETE

```sql
WITH inactive_users AS (
    SELECT id FROM users WHERE last_login < '2024-01-01'
)
DELETE FROM orders
WHERE user_id IN (SELECT id FROM inactive_users);
```

## Сравнение подзапросов и CTE

- **Подзапросы** — компактны для простых случаев, но могут ухудшать читаемость в сложных запросах
- **CTE** — улучшают читаемость, позволяют переиспользовать результат, упрощают отладку сложных запросов
