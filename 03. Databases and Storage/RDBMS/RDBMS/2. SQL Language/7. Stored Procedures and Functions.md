# Хранимые процедуры и функции

Хранимые процедуры (Stored Procedures) и функции (Functions) позволяют инкапсулировать логику SQL в переиспользуемые блоки кода, которые хранятся в базе данных.

## Хранимые процедуры (Stored Procedures)

Процедуры выполняют последовательность операций, но не возвращают значение напрямую. Могут иметь входные и выходные параметры.

### PostgreSQL

```sql
-- Создание процедуры
CREATE OR REPLACE PROCEDURE update_user_status(
    user_id INT,
    new_status VARCHAR(50)
)
LANGUAGE plpgsql
AS $$
BEGIN
    UPDATE users 
    SET status = new_status 
    WHERE id = user_id;
    
    IF NOT FOUND THEN
        RAISE EXCEPTION 'User with id % not found', user_id;
    END IF;
END;
$$;

-- Вызов процедуры
CALL update_user_status(1, 'active');
```

### MySQL

```sql
-- Создание процедуры
DELIMITER //
CREATE PROCEDURE update_user_status(
    IN user_id INT,
    IN new_status VARCHAR(50)
)
BEGIN
    UPDATE users 
    SET status = new_status 
    WHERE id = user_id;
END //
DELIMITER ;

-- Вызов процедуры
CALL update_user_status(1, 'active');
```

### Процедура с выходными параметрами

```sql
-- PostgreSQL
CREATE OR REPLACE PROCEDURE get_user_stats(
    IN user_id INT,
    OUT order_count INT,
    OUT total_spent DECIMAL(10, 2)
)
LANGUAGE plpgsql
AS $$
BEGIN
    SELECT COUNT(*), COALESCE(SUM(total), 0)
    INTO order_count, total_spent
    FROM orders
    WHERE user_id = get_user_stats.user_id;
END;
$$;

-- Вызов
CALL get_user_stats(1, NULL, NULL);
```

## Функции (Functions)

Функции возвращают значение и могут использоваться в SQL-выражениях.

### PostgreSQL

```sql
-- Скалярная функция
CREATE OR REPLACE FUNCTION calculate_discount(
    price DECIMAL(10, 2),
    discount_percent INT
)
RETURNS DECIMAL(10, 2)
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN price * (1 - discount_percent / 100.0);
END;
$$;

-- Использование функции
SELECT 
    product_name,
    price,
    calculate_discount(price, 10) AS discounted_price
FROM products;
```

### MySQL

```sql
-- Скалярная функция
DELIMITER //
CREATE FUNCTION calculate_discount(
    price DECIMAL(10, 2),
    discount_percent INT
)
RETURNS DECIMAL(10, 2)
DETERMINISTIC
READS SQL DATA
BEGIN
    RETURN price * (1 - discount_percent / 100.0);
END //
DELIMITER ;

-- Использование
SELECT 
    product_name,
    price,
    calculate_discount(price, 10) AS discounted_price
FROM products;
```

### Табличная функция (PostgreSQL)

```sql
-- Функция, возвращающая таблицу
CREATE OR REPLACE FUNCTION get_active_users()
RETURNS TABLE (
    id INT,
    username VARCHAR(50),
    email VARCHAR(255)
)
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN QUERY
    SELECT u.id, u.username, u.email
    FROM users u
    WHERE u.status = 'active';
END;
$$;

-- Использование
SELECT * FROM get_active_users();
```

## Параметры

### Типы параметров

- **IN** — входной параметр (по умолчанию)
- **OUT** — выходной параметр
- **INOUT** — входной и выходной параметр

```sql
-- PostgreSQL
CREATE OR REPLACE PROCEDURE process_order(
    IN order_id INT,
    INOUT total_amount DECIMAL(10, 2),
    OUT status VARCHAR(50)
)
LANGUAGE plpgsql
AS $$
BEGIN
    -- Логика обработки
    total_amount := total_amount * 1.1;  -- добавление налога
    status := 'processed';
END;
$$;
```

## Условная логика

### IF-THEN-ELSE

```sql
-- PostgreSQL
CREATE OR REPLACE FUNCTION get_user_level(points INT)
RETURNS VARCHAR(20)
LANGUAGE plpgsql
AS $$
BEGIN
    IF points >= 1000 THEN
        RETURN 'Gold';
    ELSIF points >= 500 THEN
        RETURN 'Silver';
    ELSE
        RETURN 'Bronze';
    END IF;
END;
$$;
```

### CASE

```sql
CREATE OR REPLACE FUNCTION get_user_level(points INT)
RETURNS VARCHAR(20)
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN CASE
        WHEN points >= 1000 THEN 'Gold'
        WHEN points >= 500 THEN 'Silver'
        ELSE 'Bronze'
    END;
END;
$$;
```

## Циклы

### LOOP

```sql
-- PostgreSQL
CREATE OR REPLACE FUNCTION factorial(n INT)
RETURNS BIGINT
LANGUAGE plpgsql
AS $$
DECLARE
    result BIGINT := 1;
    i INT := 1;
BEGIN
    LOOP
        EXIT WHEN i > n;
        result := result * i;
        i := i + 1;
    END LOOP;
    RETURN result;
END;
$$;
```

### WHILE

```sql
CREATE OR REPLACE FUNCTION factorial(n INT)
RETURNS BIGINT
LANGUAGE plpgsql
AS $$
DECLARE
    result BIGINT := 1;
    i INT := 1;
BEGIN
    WHILE i <= n LOOP
        result := result * i;
        i := i + 1;
    END LOOP;
    RETURN result;
END;
$$;
```

### FOR

```sql
CREATE OR REPLACE FUNCTION sum_range(start_val INT, end_val INT)
RETURNS INT
LANGUAGE plpgsql
AS $$
DECLARE
    total INT := 0;
BEGIN
    FOR i IN start_val..end_val LOOP
        total := total + i;
    END LOOP;
    RETURN total;
END;
$$;
```

## Обработка ошибок

```sql
-- PostgreSQL
CREATE OR REPLACE FUNCTION safe_divide(a NUMERIC, b NUMERIC)
RETURNS NUMERIC
LANGUAGE plpgsql
AS $$
BEGIN
    IF b = 0 THEN
        RAISE EXCEPTION 'Division by zero';
    END IF;
    RETURN a / b;
EXCEPTION
    WHEN OTHERS THEN
        RAISE NOTICE 'Error: %', SQLERRM;
        RETURN NULL;
END;
$$;
```

## Управление транзакциями

Процедуры и функции могут управлять транзакциями:

```sql
-- PostgreSQL
CREATE OR REPLACE PROCEDURE transfer_money(
    from_account INT,
    to_account INT,
    amount DECIMAL(10, 2)
)
LANGUAGE plpgsql
AS $$
BEGIN
    -- Начало транзакции
    BEGIN
        UPDATE accounts SET balance = balance - amount WHERE id = from_account;
        UPDATE accounts SET balance = balance + amount WHERE id = to_account;
        COMMIT;
    EXCEPTION
        WHEN OTHERS THEN
            ROLLBACK;
            RAISE;
    END;
END;
$$;
```

## Удаление процедур и функций

```sql
-- PostgreSQL
DROP PROCEDURE IF EXISTS update_user_status;
DROP FUNCTION IF EXISTS calculate_discount;

-- MySQL
DROP PROCEDURE IF EXISTS update_user_status;
DROP FUNCTION IF EXISTS calculate_discount;
```

## Преимущества

- **Производительность** — код компилируется и кэшируется
- **Безопасность** — контроль доступа на уровне базы данных
- **Переиспользование** — одна процедура/функция для множества приложений
- **Целостность данных** — бизнес-логика централизована в базе данных

## Недостатки

- **Переносимость** — синтаксис различается между СУБД
- **Отладка** — сложнее отлаживать, чем код приложения
- **Версионирование** — сложнее управлять версиями, чем кодом приложения
