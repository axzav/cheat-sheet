# Механизмы блокировок

Блокировки (locks) используются для управления конкурентным доступом к данным и предотвращения конфликтов между транзакциями.

## Типы блокировок

### Shared Lock (Разделяемая блокировка)

Разрешает чтение данных, но запрещает запись. Несколько транзакций могут одновременно удерживать shared lock на одних и тех же данных.

- Используется для операций SELECT
- Совместима с другими shared locks
- Несовместима с exclusive locks

### Exclusive Lock (Исключительная блокировка)

Запрещает как чтение, так и запись данных другими транзакциями. Только одна транзакция может удерживать exclusive lock на данных.

- Используется для операций INSERT, UPDATE, DELETE
- Несовместима с любыми другими блокировками
- Гарантирует, что только одна транзакция может изменять данные

### Intent Lock (Намеренная блокировка)

Используется для указания намерения установить блокировку на более низком уровне иерархии (например, на строке или странице).

- **Intent Shared (IS)**: Намерение установить shared lock на более низком уровне
- **Intent Exclusive (IX)**: Намерение установить exclusive lock на более низком уровне
- **Shared Intent Exclusive (SIX)**: Shared lock на уровне таблицы и intent exclusive на более низких уровнях

## Уровни блокировок

### Row-level Lock (Блокировка на уровне строки)

Блокирует отдельные строки таблицы. Наиболее гранулярный уровень блокировки, обеспечивает максимальную конкурентность.

- Минимальный конфликт между транзакциями
- Больше накладных расходов на управление блокировками
- Используется в PostgreSQL и MySQL InnoDB

### Page-level Lock (Блокировка на уровне страницы)

Блокирует страницу данных (обычно 8KB). Компромисс между гранулярностью и производительностью.

### Table-level Lock (Блокировка на уровне таблицы)

Блокирует всю таблицу. Наименее гранулярный уровень, но самый быстрый для управления.

- Минимальные накладные расходы
- Максимальный конфликт между транзакциями
- Используется в MySQL MyISAM

## Явные блокировки

### SELECT FOR UPDATE

Блокирует выбранные строки для последующего обновления:

```sql
BEGIN;
SELECT * FROM accounts WHERE id = 1 FOR UPDATE;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
COMMIT;
```

### SELECT FOR SHARE (LOCK IN SHARE MODE в MySQL)

Блокирует выбранные строки для чтения, предотвращая их изменение другими транзакциями:

```sql
BEGIN;
SELECT * FROM accounts WHERE id = 1 FOR SHARE;
-- другие транзакции могут читать, но не изменять
COMMIT;
```

### Advisory Locks (Консультативные блокировки)

Блокировки на уровне приложения, не связанные с конкретными данными. Используются для координации между процессами.

**PostgreSQL**:

```sql
-- Получить консультативную блокировку
SELECT pg_advisory_lock(123);

-- Освободить блокировку
SELECT pg_advisory_unlock(123);
```

## Deadlocks (Взаимоблокировки)

Deadlock возникает, когда две или более транзакций ждут друг друга, создавая циклическую зависимость.

### Пример deadlock

```
Транзакция A: блокирует строку 1, пытается заблокировать строку 2
Транзакция B: блокирует строку 2, пытается заблокировать строку 1
```

### Предотвращение deadlocks

- Всегда блокировать ресурсы в одинаковом порядке
- Использовать короткие транзакции
- Избегать блокировок нескольких ресурсов одновременно
- Использовать таймауты для блокировок

### Обработка deadlocks

СУБД автоматически обнаруживает deadlocks и откатывает одну из транзакций:

```sql
-- PostgreSQL: автоматический откат при deadlock
ERROR: deadlock detected
DETAIL: Process 12345 waits for ShareLock on transaction 67890; blocked by process 11111.
```

## Автоматические блокировки

СУБД автоматически устанавливает блокировки для операций:

- **SELECT**: shared lock (в зависимости от уровня изоляции)
- **INSERT**: exclusive lock на новую строку
- **UPDATE**: exclusive lock на изменяемые строки
- **DELETE**: exclusive lock на удаляемые строки

## Совместимость блокировок

| Текущая блокировка | Запрошенная блокировка | Результат |
|-------------------|------------------------|-----------|
| Shared            | Shared                 | Разрешено |
| Shared            | Exclusive              | Заблокировано |
| Exclusive         | Shared                 | Заблокировано |
| Exclusive         | Exclusive              | Заблокировано |
