# Data Types

Типы данных (data types) определяют, какие значения могут храниться в столбце таблицы. Правильный выбор типа данных важен для целостности данных, производительности и эффективного использования хранилища.

## Числовые типы

### Целые числа

**INTEGER / INT**
- Размер: обычно 4 байта
- Диапазон: -2,147,483,648 до 2,147,483,647
- Использование: основной тип для целых чисел

**SMALLINT**
- Размер: обычно 2 байта
- Диапазон: -32,768 до 32,767
- Использование: для небольших чисел

**BIGINT**
- Размер: обычно 8 байт
- Диапазон: очень большой
- Использование: для больших чисел (ID, счетчики)

**TINYINT**
- Размер: обычно 1 байт
- Диапазон: -128 до 127 (или 0 до 255 для UNSIGNED)
- Использование: для очень маленьких чисел (флаги, статусы)

### Числа с плавающей точкой

**FLOAT**
- Приблизительное значение
- Использование: для научных вычислений, где точность не критична

**DOUBLE / DOUBLE PRECISION**
- Более точное приблизительное значение
- Использование: для более точных вычислений

**DECIMAL / NUMERIC**
- Точное значение с фиксированной точностью
- Синтаксис: `DECIMAL(precision, scale)`
- Пример: `DECIMAL(10, 2)` — 10 цифр, 2 после запятой
- Использование: для денежных сумм, где важна точность

## Строковые типы

### Строки фиксированной длины

**CHAR(n)**
- Фиксированная длина n символов
- Занимает n байт независимо от содержимого
- Использование: для данных фиксированной длины (коды, статусы)

### Строки переменной длины

**VARCHAR(n)**
- Переменная длина до n символов
- Занимает место только для фактической длины строки
- Использование: для текста переменной длины (имена, описания)

**TEXT**
- Очень длинные строки
- Ограничения зависят от СУБД
- Использование: для больших текстовых полей

**TINYTEXT, MEDIUMTEXT, LONGTEXT**
- Варианты TEXT с разными ограничениями длины

## Бинарные типы

**BINARY(n)**
- Фиксированная длина бинарных данных

**VARBINARY(n)**
- Переменная длина бинарных данных

**BLOB (Binary Large Object)**
- Для хранения больших бинарных данных (изображения, файлы)
- Варианты: TINYBLOB, MEDIUMBLOB, LONGBLOB

## Дата и время

**DATE**
- Только дата (год, месяц, день)
- Формат: YYYY-MM-DD

**TIME**
- Только время (часы, минуты, секунды)
- Формат: HH:MM:SS

**DATETIME**
- Дата и время вместе
- Формат: YYYY-MM-DD HH:MM:SS

**TIMESTAMP**
- Дата и время с автоматическим обновлением
- Обычно автоматически обновляется при изменении строки
- Может иметь ограничения по диапазону дат

**YEAR**
- Только год
- Обычно 4 цифры

## Логические типы

**BOOLEAN / BOOL**
- TRUE или FALSE
- В некоторых СУБД реализуется как TINYINT(1)

## JSON

**JSON / JSONB**
- Хранение данных в формате JSON
- JSONB (PostgreSQL) — бинарный формат с индексацией
- Использование: для полуструктурированных данных

## Массивы

**ARRAY**
- Массив значений одного типа
- Поддерживается в PostgreSQL
- Пример: `INTEGER[]`, `TEXT[]`

## Геометрические типы

**GEOMETRY, POINT, POLYGON**
- Для хранения геометрических данных
- Используется с расширениями типа PostGIS

## Выбор типа данных

### Принципы

1. **Минимальный достаточный размер**: Выбирать наименьший тип, который покрывает все возможные значения
2. **Точность для чисел**: Использовать DECIMAL для денег, FLOAT/DOUBLE для приблизительных значений
3. **Длина строк**: Использовать VARCHAR вместо CHAR, если длина переменная
4. **NULL значения**: Учитывать, может ли поле быть NULL

### Примеры

```sql
-- Правильный выбор типов
CREATE TABLE users (
    id BIGINT PRIMARY KEY,              -- Большой диапазон для ID
    email VARCHAR(255) NOT NULL,        -- Email переменной длины
    age TINYINT UNSIGNED,               -- Возраст от 0 до 255
    balance DECIMAL(10, 2),             -- Деньги с точностью до цента
    created_at TIMESTAMP DEFAULT NOW(), -- Дата создания
    is_active BOOLEAN DEFAULT TRUE      -- Флаг активности
);
```

## Особенности по СУБД

### PostgreSQL
- Поддержка массивов, JSONB, пользовательских типов
- Богатые типы для даты/времени с timezone

### MySQL
- Множество вариантов числовых и строковых типов
- Автоматическое преобразование типов может быть неожиданным

### SQL Server
- Специфические типы: MONEY, SMALLMONEY
- Поддержка XML типа
