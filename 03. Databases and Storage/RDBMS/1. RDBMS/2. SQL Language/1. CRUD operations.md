# CRUD операции

CRUD (Create, Read, Update, Delete) — основные операции для работы с данными в базе данных.

## CREATE (Создание)

### INSERT — вставка данных

```sql
-- Вставка одной записи
INSERT INTO users (username, email, age)
VALUES ('john_doe', 'john@example.com', 25);

-- Вставка нескольких записей
INSERT INTO users (username, email, age)
VALUES 
    ('jane_doe', 'jane@example.com', 30),
    ('bob_smith', 'bob@example.com', 28);

-- Вставка из результата запроса
INSERT INTO users_backup (username, email, age)
SELECT username, email, age
FROM users
WHERE age > 25;
```

## READ (Чтение)

### SELECT — выборка данных

```sql
-- Выборка всех столбцов
SELECT * FROM users;

-- Выборка конкретных столбцов
SELECT username, email FROM users;

-- Выборка с условием
SELECT * FROM users WHERE age > 25;

-- Выборка с сортировкой
SELECT * FROM users ORDER BY age DESC;

-- Выборка с ограничением количества
SELECT * FROM users LIMIT 10;

-- Выборка с пропуском записей
SELECT * FROM users OFFSET 10 LIMIT 5;
```

### DISTINCT — уникальные значения

```sql
SELECT DISTINCT city FROM users;
```

### WHERE — условия фильтрации

```sql
-- Простые условия
SELECT * FROM users WHERE age = 25;
SELECT * FROM users WHERE age > 25 AND city = 'Moscow';
SELECT * FROM users WHERE age IN (25, 30, 35);
SELECT * FROM users WHERE email LIKE '%@gmail.com';

-- NULL проверки
SELECT * FROM users WHERE email IS NULL;
SELECT * FROM users WHERE email IS NOT NULL;
```

## UPDATE (Обновление)

### UPDATE — изменение данных

```sql
-- Обновление одной записи
UPDATE users 
SET email = 'newemail@example.com' 
WHERE id = 1;

-- Обновление нескольких полей
UPDATE users 
SET email = 'newemail@example.com', age = 26 
WHERE id = 1;

-- Обновление нескольких записей
UPDATE users 
SET status = 'inactive' 
WHERE last_login < '2024-01-01';

-- Обновление с использованием подзапроса
UPDATE users 
SET department_id = (
    SELECT id FROM departments WHERE name = 'IT'
)
WHERE username = 'john_doe';
```

## DELETE (Удаление)

### DELETE — удаление данных

```sql
-- Удаление конкретной записи
DELETE FROM users WHERE id = 1;

-- Удаление нескольких записей
DELETE FROM users WHERE status = 'inactive';

-- Удаление всех записей (осторожно!)
DELETE FROM users;

-- Безопасное удаление всех записей (быстрее, но не логируется)
TRUNCATE TABLE users;
```

## Важные замечания

- Всегда использовать `WHERE` в `UPDATE` и `DELETE`, если не требуется изменение всех записей
- Перед массовыми операциями рекомендуется делать резервную копию или использовать транзакции
- `TRUNCATE` быстрее `DELETE`, но не может быть откачено в некоторых СУБД
