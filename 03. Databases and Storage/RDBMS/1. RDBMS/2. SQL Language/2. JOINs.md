# JOIN операции

Объединение таблиц (JOIN) — операция, позволяющая объединять данные из двух или более таблиц на основе общих столбцов. Существует несколько типов объединений, каждый из которых имеет свои особенности.

## INNER JOIN

Возвращает строки, когда существует совпадение в обеих таблицах. Это наиболее часто используемый тип объединения.

```sql
SELECT columns
FROM table1
INNER JOIN table2
ON table1.common_field = table2.common_field;

-- Пример
SELECT u.username, o.order_date, o.total
FROM users u
INNER JOIN orders o ON u.id = o.user_id;
```

## LEFT JOIN (LEFT OUTER JOIN)

Возвращает все строки из левой таблицы и соответствующие строки из правой таблицы. Если совпадения нет, в столбцах правой таблицы будут NULL.

```sql
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.common_field = table2.common_field;

-- Пример: все пользователи и их заказы (если есть)
SELECT u.username, o.order_date, o.total
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;
```

## RIGHT JOIN (RIGHT OUTER JOIN)

Возвращает все строки из правой таблицы и соответствующие строки из левой таблицы. Если совпадения нет, в столбцах левой таблицы будут NULL.

```sql
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.common_field = table2.common_field;

-- Пример: все заказы и пользователи (если есть)
SELECT u.username, o.order_date, o.total
FROM users u
RIGHT JOIN orders o ON u.id = o.user_id;
```

## FULL JOIN (FULL OUTER JOIN)

Возвращает все строки из обеих таблиц, заполняя NULL там, где нет совпадений. Может привести к большому количеству строк при наличии множества несовпадающих данных.

```sql
SELECT columns
FROM table1
FULL JOIN table2
ON table1.common_field = table2.common_field;

-- Пример: все пользователи и все заказы
SELECT u.username, o.order_date, o.total
FROM users u
FULL JOIN orders o ON u.id = o.user_id;
```

## CROSS JOIN

Возвращает декартово произведение двух таблиц — каждая строка одной таблицы соединяется с каждой строкой другой таблицы. Не требует условия ON.

```sql
SELECT columns
FROM table1
CROSS JOIN table2;

-- Пример: все комбинации размеров и цветов
SELECT s.size, c.color
FROM sizes s
CROSS JOIN colors c;
```

## SELF JOIN

Объединение таблицы с самой собой. Полезно для сравнения строк внутри одной таблицы.

```sql
SELECT a.columns, b.columns
FROM table1 a
JOIN table1 b ON a.common_field = b.common_field
WHERE condition;

-- Пример: найти сотрудников с одинаковым менеджером
SELECT e1.name AS employee, e2.name AS manager
FROM employees e1
JOIN employees e2 ON e1.manager_id = e2.id;
```

## Множественные JOIN

Можно объединять несколько таблиц в одном запросе:

```sql
SELECT u.username, o.order_date, p.product_name, oi.quantity
FROM users u
INNER JOIN orders o ON u.id = o.user_id
INNER JOIN order_items oi ON o.id = oi.order_id
INNER JOIN products p ON oi.product_id = p.id;
```

## Условия JOIN

Условие объединения может включать несколько столбцов:

```sql
SELECT *
FROM table1 t1
JOIN table2 t2 ON t1.col1 = t2.col1 
              AND t1.col2 = t2.col2;
```
