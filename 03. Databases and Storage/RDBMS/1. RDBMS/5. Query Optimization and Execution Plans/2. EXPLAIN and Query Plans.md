# EXPLAIN и планы выполнения запросов

EXPLAIN — SQL-команда, показывающая, как база данных будет выполнять запрос. Необходима для понимания производительности запросов и их оптимизации.

## Базовое использование

```sql
EXPLAIN SELECT * FROM users WHERE email = 'user@example.com';
```

## EXPLAIN ANALYZE

Показывает фактический план выполнения со статистикой времени выполнения:

```sql
EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'user@example.com';
```

## Ключевые метрики

- **Execution Time** — общее время выполнения запроса
- **Planning Time** — время, потраченное на планирование запроса
- **Seq Scan** — последовательное сканирование (обычно медленно для больших таблиц)
- **Index Scan** — использование индекса (обычно быстрее)
- **Cost** — оценка стоимости операции
- **Rows** — количество обработанных строк
- **Filter** — условия, применяемые для фильтрации строк

## Основные операции в плане выполнения

- **Seq Scan** — полное сканирование таблицы
- **Index Scan** — сканирование индекса
- **Index Only Scan** — чтение только из индекса (самый быстрый)
- **Bitmap Heap Scan** — использование bitmap индекса
- **Nested Loop** — операция соединения (nested loop join)
- **Hash Join** — соединение на основе хеш-таблицы
- **Merge Join** — соединение методом слияния
- **Sort** — операция сортировки
- **Aggregate** — операция агрегации

## Советы по оптимизации

1. Искать последовательные сканирования на больших таблицах — возможно, нужны индексы
2. Проверять, используются ли индексы
3. Убеждаться, что методы соединения подходят для задачи
4. Обращать внимание на дорогие операции, такие как сортировка больших наборов данных
5. Использовать EXPLAIN ANALYZE для сравнения фактических и оцененных затрат

## PostgreSQL

```sql
-- Показать детальный план запроса
EXPLAIN (ANALYZE, BUFFERS, VERBOSE) SELECT ...;

-- Показать в формате JSON
EXPLAIN (FORMAT JSON) SELECT ...;
```

## MySQL

```sql
-- Показать расширенную информацию
EXPLAIN EXTENDED SELECT ...;

-- Показать предупреждения
EXPLAIN SELECT ...;
SHOW WARNINGS;
```
