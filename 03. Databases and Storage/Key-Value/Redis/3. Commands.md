# Redis commands

## Commands

Все значения по умолчанию строки. Если установить значение как число в php то при получении значения это все равно будет string

```redis
SET foo 42
SET bazz "value_here" EX 20 \\ установить TTL на 20 секунд
SET bazz "value_here" PX 20 \\ установить TTL на 20 милисекунд

APPEND foo 1 // добавить к строке подстоку. Если foo был = "42", то теперь значение будет "421". Команда возвращает количество строк по значения

INCR foo // увеличить число на единицу. Все значения в редис хранятся как строки. Но если попытаться выполнить команду INCR на строке без числовых символов, то редис вернет ошибку. В случае успеха вернет новое значение после инкремента
DECR foo // декремент. Счетчики 64 бита

GET foo //строка "42" | (nil)
KEYS * //вывести все ключи. * - паттерн

GETSET foo 99 // вернет предыдущее значение foo и установит новое в 99

EXISTS foo bar //возвращает количесто найденных ключей из списка аргументов
FLUSHALL //очистить базу данных
```
