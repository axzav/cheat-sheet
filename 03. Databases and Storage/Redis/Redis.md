# Redis (Remote Dictionary Service)

Redis — это **main memory** база данных (DBMS). Основной датасет хранится в оперативной памяти.

Основные возможности:
- in-memory key–value datastore
- message broker
- pub/sub, streams, LUA, replication, cluster и т.д.

Исторически Redis был open source (BSD), но начиная с версии 7.2 лицензия была изменена на RSAL/SSPL-подобную модель
После смены лицензии Redis 7.2 AWS, Google, Oracle и другие крупные игроки сделали fork Redis 7.2 под open-source лицензией.
Так появился Valkey, полностью open source

**Легкий и Быстрый**. 
Малый вес приложения (меньше 10 мб) и малое потребление оперативной памяти (меньше 3 мб пустой инстанс).
1М записей занимает меньше 100 МБ.
Более 1М операций в секунду.

**Множество структур данных.**
**Низкий порог входа**

Ядро редиса однопоточное. Это значит, что транзакции всегда выполняются последовательно. Транзакции атомарны и не могут быть откачены (rollback)

Redis поддерживает Lua скрипты. Они также выполняются атомарно. Аналог хранимых процедур.


Основные сферы применения:
- Кэширование
- Хранилище сессий
- Работа с очередями
- Распределенные блокировки 
- Счетчики и метрики
- Промежуточное сохранение логов

## Redis CLI

Для подключения через командную строку:
```bash
redis-cli
```
