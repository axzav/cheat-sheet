# Streams

* Лог событий
* append-only
* consumer groups
* альтернатива Kafka-lite

Используют как lightweight event bus.

```redis
XADD mystream * user alex action login
XRANGE mystream - +
XREAD COUNT 10 STREAMS mystream 0
```

Consumer group:

```redis
XGROUP CREATE mystream group1 0
XREADGROUP GROUP group1 consumer1 STREAMS mystream >
```

```php
$redis->xAdd('mystream', '*', [
    'user' => 'alex',
    'action' => 'login'
]);

$messages = $redis->xRead(['mystream' => 0], 10);
```
