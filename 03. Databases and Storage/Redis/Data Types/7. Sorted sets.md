# Sorted Set (ZSet)

* Уникальные элементы + score
* Автоматическая сортировка по score
* Используется для рейтингов, leaderboards

```redis
ZADD leaderboard 100 user1
ZADD leaderboard 200 user2
ZRANGE leaderboard 0 -1 WITHSCORES
ZREVRANGE leaderboard 0 10 WITHSCORES
```

```php
$redis->zAdd('leaderboard', 100, 'user1');
$redis->zAdd('leaderboard', 200, 'user2');

$top = $redis->zRevRange('leaderboard', 0, 10, true);
```
