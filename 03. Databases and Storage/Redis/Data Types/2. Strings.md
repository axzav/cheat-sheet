# Strings

Базовый тип, до **512 MB** на значение
Все значения по умолчанию строки. Если установить значение как число в php то при получении значения это все равно будет string
Подходит для: кэша, JSON, токенов, счётчиков

```redis
SET key value
GET key
KEYS * //вывести все ключи. * - паттерн

INCR counter // увеличить число на единицу. Все значения в редис хранятся как строки. Но если попытаться выполнить команду INCR на строке без числовых символов, то редис вернет ошибку. В случае успеха вернет новое значение после инкремента
DECR counter

APPEND key " world"

SET bazz "value_here" EX 20 // установить TTL на 20 секунд
SET bazz "value_here" PX 20 // установить TTL на 20 милисекунд

GETSET foo 99 // вернет предыдущее значение foo и установит новое в 99

EXISTS foo bar //возвращает количесто найденных ключей из списка аргументов

FLUSHALL //очистить базу данных
```

```php
$redis->set('key', 'value');
$value = $redis->get('key');

$redis->set('counter', 1);
$redis->incr('counter');

$redis->set('temp', 'data', ['ex' => 60]);
```


## Bitmap

Это обычный String, но работа побитово.

* Эффективное хранение флагов
* Подходит для: online/offline, отметки активности, feature flags


```redis
SETBIT users:online 1001 1
GETBIT users:online 1001
BITCOUNT users:online
```

```php
$redis->setBit('users:online', 1001, 1);
$status = $redis->getBit('users:online', 1001);
$count = $redis->bitCount('users:online');
```


## Bitfield

* Хранение нескольких чисел внутри одного String
* Контроль размера (u8, i16 и т.д.)
* Подходит для packed-структур

```redis
BITFIELD mykey SET u8 0 255
BITFIELD mykey GET u8 0
BITFIELD mykey INCRBY u8 0 1
```

```php
$redis->rawCommand('BITFIELD', 'mykey', 'SET', 'u8', 0, 255);
$redis->rawCommand('BITFIELD', 'mykey', 'GET', 'u8', 0);
```
