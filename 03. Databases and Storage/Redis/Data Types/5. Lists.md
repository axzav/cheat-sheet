# Lists

* Упорядоченный список
* Linked-list поведение
* Подходит для очередей

```redis
LPUSH queue job1
RPUSH queue job2
LPOP queue
LRANGE queue 0 -1
```

```php
$redis->lPush('queue', 'job1');
$redis->rPush('queue', 'job2');

$job = $redis->lPop('queue');
$all = $redis->lRange('queue', 0, -1);
```
