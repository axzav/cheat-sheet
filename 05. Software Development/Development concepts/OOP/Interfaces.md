# Interfaces

Интерфейсы — это структуры, которые помогают определять шаблонные методы, которые должны быть реализованы в классах, их имплементирующих. Интерфейсы предоставляют способ формализовать определённые аспекты поведения объекта, гарантируя, что классы реализуют предписанные методы. Это полезно для создания унифицированного API и для обеспечения согласованности между различными частями приложения.

## Особенности

### Методы интерфейса
Все методы в нем должны быть публичными и не могут иметь реализацию. Тело каждого метода определяется только в классах, которые реализуют интерфейс.

### Наследование интерфейсов
Могут наследовать другие интерфейсы, и класс может реализовывать множество интерфейсов, что обеспечивает гибкость множественного наследования через интерфейсное программирование.

## Зачем они нужны?

### Согласованность: 
Обеспечивают стандартизацию, требуя от классов реализацию определённых методов.

### Гибкость

Различные классы могут предоставлять свою собственную реализацию интерфейса, что позволяет программам динамически изменять поведение.

### Разделение и инкапсуляция

Позволяют создавать код, который может работать с любым объектом, реализующим интерфейс, без знания конкретной реализации этого объекта.


Пример - интерфесы из PSR и фреймворков
