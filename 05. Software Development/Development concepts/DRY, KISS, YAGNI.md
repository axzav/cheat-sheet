# DRY, KISS, YAGNI

**DRY** - Do not repeat yourself. Избегай повторного написания кода, используй универсальные библиотеки и функции

**KISS** - Keep it simple, stupid. Не усложняй код, используй распространенные фреймворки и шаблоны проектирования для решения задачи, не изобретай велосипед

**YAGNI** - You Ain't gonna need it. Тебе это не понадобится. Это обозначает, что нужно решать только поставленную задачу и отказаться от избыточного функционала
