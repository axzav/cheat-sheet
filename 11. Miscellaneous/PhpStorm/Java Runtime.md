# Java Runtime

Help | Find Action (`Ctrl`+`Shift`+`A`) -> `Choose Boot Java Runtime for the IDE`

Тут можно поменять дефолтный рантайм на другой. Это может понадобиться для смены отрисовки шрифтов.

**Перед обновлением PhpStrom нужно сбросить рантайм на дефолтный!**

Варианты сборок:
* **JBR (JetBrains Runtime)**: Это базовая версия OpenJDK, которую JetBrains модифицировали под свои нужды (исправили баги с фокусом окон, HiDPI, клавиатурными раскладками и, конечно, шрифтами). **Использовать ее для работы**
* **JBRSDK**: Это JBR плюс инструменты разработчика (компилятор javac и прочее).
* **JCEF (Java Chromium Embedded Framework)**: Это встроенный движок Chrome. Он нужен для отображения HTML-контента внутри IDE: превью Markdown, документация PHP, интерактивные карты и т.д. **Всегда выбирать версию with JCEF**

Теги и модификации:
* **vanilla**: Чистая сборка без дополнительных модулей и специфических патчей. Обычно работает стабильнее, но может лишиться некоторых оптимизаций JetBrains.
* **fast debug**: Спецсборка для разработчиков с включенными проверками кода. Она работает медленнее и потребляет больше памяти. Обычному пользователю она не нужна.
* **legacy**: Устаревшие сборки (например, на базе Java 11 или 17, когда IDE уже требует 21). Обычно их используют только для решения проблем совместимости на старом железе.
* **FreeType**: В эту сборку JBR вшита собственная версия библиотеки FreeType, скомпилированная самими JetBrains с их специфическими патчами.


## FreeType

В Linux есть два способа, как Java может работать с FreeType:
* **System FreeType (по умолчанию)**: Java использует библиотеку, установленную в системе. Это значит, что если в системе настроен сильный хинтинг или выключено субпиксельное сглаживание, PHPStorm подхватит эти настройки. Иногда это приводит к тому, что шрифты выглядят «кривыми» или слишком тонкими.
* **Bundled FreeType (с тегом FreeType)**: В эту сборку JBR вшита собственная версия библиотеки FreeType, скомпилированная самими JetBrains с их специфическими патчами.
