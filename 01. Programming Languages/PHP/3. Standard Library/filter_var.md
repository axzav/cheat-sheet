Обе функции в PHP проверяют, является ли значение числом, но они делают это по-разному.

### 1. `filter_var($value, FILTER_VALIDATE_INT)`

* Проверяет, является ли значение **целым числом (integer)**.
* Возвращает **само число**, если оно валидно, и `false` в противном случае.
* Не допускает числа в виде строки с пробелами или числа с плавающей точкой.

Примеры:

```php
var_dump(filter_var("123", FILTER_VALIDATE_INT)); // int(123)
var_dump(filter_var("123.45", FILTER_VALIDATE_INT)); // bool(false)
var_dump(filter_var(" 123 ", FILTER_VALIDATE_INT)); // bool(false)
var_dump(filter_var("abc", FILTER_VALIDATE_INT)); // bool(false)
```

### 2. `is_numeric($value)`

* Проверяет, может ли значение быть интерпретировано как число (целое или дробное).
* Поддерживает **числа с плавающей точкой** и **числа в виде строки**.
* Возвращает `true` или `false`.

Примеры:

```php
var_dump(is_numeric("123")); // true
var_dump(is_numeric("123.45")); // true
var_dump(is_numeric(" 123 ")); // true (но filter_var вернет false)
var_dump(is_numeric("1e3")); // true (экспоненциальная запись)
var_dump(is_numeric("abc")); // false
```

### Основные различия:

| Функция                                   | Проверяет только целые числа | Поддерживает строки с пробелами | Поддерживает float (например, `"123.45"`) | Возвращает само число (а не `true/false`) |
| ----------------------------------------- | ---------------------------- | ------------------------------- | ----------------------------------------- | ----------------------------------------- |
| `filter_var($value, FILTER_VALIDATE_INT)` | ✅                            | ❌                               | ❌                                         | ✅ (или `false`)                           |
| `is_numeric($value)`                      | ✅                            | ✅                               | ✅                                         | ❌ (`true/false`)                          |

### Когда какую использовать?

* Если нужно строгое соответствие **целому числу** → `filter_var($value, FILTER_VALIDATE_INT)`.
* Если нужно просто проверить, является ли значение **числом в любом формате** → `is_numeric($value)`.
