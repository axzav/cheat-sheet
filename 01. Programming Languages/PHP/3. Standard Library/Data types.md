# Типы данных в PHP

PHP поддерживает несколько основных типов данных, которые можно разделить на три категории: простые (скалярные) типы, составные типы и специальные типы.

## Простые (скалярные) типы

### Integer (целое число)

Представляет целое число, может быть положительным или отрицательным.

```php
$a = 123;      // Положительное число
$b = -456;     // Отрицательное число
$c = 0;        // Ноль
$d = 0x1A;     // Шестнадцатеричное (26)
$e = 0b1010;   // Двоичное (10)
$f = 1_234_567; // С разделителями (PHP 7.4+)
```

### Float (число с плавающей точкой)

Используется для представления дробных чисел.

```php
$a = 3.14;
$b = 1.2e3;    // 1200.0
$c = 7E-10;    // 0.0000000007
$d = 1_234.567; // С разделителями (PHP 7.4+)
```

**Важно:** Float хранит приблизительные значения. Для денег используйте целые числа (центы/копейки) или BCMath/GMP.

### String (строка)

Последовательность символов для работы с текстом.

```php
$str1 = 'Одинарные кавычки';
$str2 = "Двойные кавычки";
$str3 = <<<EOD
Heredoc синтаксис
EOD;
```

### Boolean (логический тип)

Имеет два значения: `true` и `false`.

```php
$isActive = true;
$isDeleted = false;
```

## Составные типы

### Array (массив)

Коллекция данных, которая может содержать элементы любого типа.

```php
// Индексированный массив
$arr1 = [1, 2, 3];

// Ассоциативный массив
$arr2 = ['name' => 'John', 'age' => 30];

// Многомерный массив
$arr3 = [
    [1, 2, 3],
    [4, 5, 6]
];
```

### Object (объект)

Экземпляр класса, который содержит данные (свойства) и методы для работы с этими данными.

```php
class User {
    public $name;
    public function getName() {
        return $this->name;
    }
}

$user = new User();
```

## Специальные типы

### Resource (ресурс)

Ссылка на внешние ресурсы, такие как файлы, соединения с базами данных и т.д.

```php
$file = fopen('file.txt', 'r'); // Resource
$pdo = new PDO(...);             // Объект, не resource
```

### NULL

Тип, имеющий одно значение `NULL`, используется для обозначения переменной без значения.

```php
$var = null;
unset($var); // Переменная становится null
```

### Callable

Псевдотип, представляющий функцию или метод, который может быть вызван.

```php
$callable1 = 'functionName';
$callable2 = ['ClassName', 'methodName'];
$callable3 = function() { return true; };
$callable4 = $object; // Если объект имеет метод __invoke()
```

## Проверка типов

```php
is_int($var);        // Проверка на integer
is_float($var);      // Проверка на float
is_string($var);     // Проверка на string
is_bool($var);       // Проверка на boolean
is_array($var);      // Проверка на array
is_object($var);     // Проверка на object
is_resource($var);   // Проверка на resource
is_null($var);       // Проверка на null
is_callable($var);   // Проверка на callable
gettype($var);       // Получить тип в виде строки
```

## Приведение типов

```php
(int) $var;      // К integer
(float) $var;    // К float
(string) $var;   // К string
(bool) $var;     // К boolean
(array) $var;    // К array
(object) $var;   // К object
```
