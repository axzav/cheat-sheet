# PHP Datatypes

Есть несколько основных типов данных, каждый из которых служит определённым целям при программировании. Типы данных можно разделить на три основные категории: простые (или скалярные) типы, составные типы и специальные типы.

## Простые (скалярные) типы

**Integer (целое число)** — представляет собой целое число, может быть как положительным, так и отрицательным. Например, -123, 0, 456.

**Float (действительное число)** — число с плавающей точкой. Используется для представления дробных чисел, например, 3.14, 0.001.

**String (строка)** — последовательность символов, используется для работы с текстом. Например, "Hello, world!".

**Boolean (булев тип)** — имеет два значения: true (истина) и false (ложь). Используется для логических операций.

## Составные типы

**Array (массив)** — коллекция данных, которая может содержать элементы любого типа. Массивы в PHP могут быть как индексированными (с числовыми ключами), так и ассоциативными (с ключами-строками).

**Object (объект)** — экземпляр класса, который содержит данные (свойства) и методы для работы с этими данными. Объекты создаются на основе классов.

## Специальные типы

**Resource (ресурс)** — представляет собой ссылку на внешние ресурсы, такие как файлы, соединения с базами данных и т.д.

**NULL** — тип, имеющий одно значение NULL, используется для обозначения переменной без значения.
