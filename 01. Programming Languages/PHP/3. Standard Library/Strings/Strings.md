# Strings

Начиная с 7й версии php строки в пхп стали binary-safe, что обозначает, что строка может быть любой длины и содержать бинарные данные (аудио, изображение, текст и тд)

Внутренним представлением строк в Zend Engine является структура `zend_string`

```c
struct _zend_string {
    zend_refcounted_h gc;
    zend_ulong        h;
    size_t            len;
    char              val[1];
};
```

По внутреннему устройству строки представляют собой массив байт с переменной, хранящей длину массива. Строки пхп не знают ничего о кодировке строки

- Строки по сути тип **char[]**. Строки **binary-safe**
- Часть строки не отбрасывается после **Null-байта**
- К символам (байтам) строки можно обращаться с помощью синтаксиса доступа к **элементам массива []**
- Строки ничего не знают о **кодировке**, большинство стандартных функций работают с байтами
- Для работы как с текстовой строкой безопасно использовать **mb_*** функции

```php
$str = "Привет\n\t";

var_dump(strlen($str));    // int(14) - 12 байт на "Привет" (2 байта на киррилический символ)
var_dump(ord($str[0]));    // соответсвует unsigned байту 208
var_dump(ord($str[1]));    // соответсвует unsigned байту 159
var_dump($str[0].$str[1]); // string(2) "П" - (два байта на символ)
var_dump($str[0]);         // string(1) "�" - В однобайтовой ASCII (0-127) нет предствления для байта 208

var_dump(mb_strlen($str)); // int(8) - 6 символов кирилицы + 2 управляющих
```

## Варианты литералов

**Одинарные кавычки:**
- управляющие последовательности не обрабатываются
- текст интерпретируется как есть (перенос строки будет учтен, табы тоже)

```php
echo 'Это — простая строка';
echo 'В строки также разрешено вставлять
символ новой строки, способом, которым записан этот текст, —
так делать нормально';
// Выводит: Однажды Арнольд сказал: "I'll be back"
echo 'Однажды Арнольд сказал: "I\'ll be back"';
// Выводит: Вы удалили C:\*.*?
echo 'Вы удалили C:\\*.*?';
// Выводит: Вы удалили C:\*.*?
echo 'Вы удалили C:\*.*?';
// Выводит: Это не будет развёрнуто: \n в новую строку
echo 'Это не будет развёрнуто: \n в новую строку';
// Выводит: Переменные $expand и $either также не разворачиваются
echo 'Переменные $expand и $either также не разворачиваются';
```

Двойные кавычки:
- управляющие последовательности обрабатываются
- имена переменных обрабатываются

```php
// Работает
echo "Ширина квадрата составляет {$square->width}00 сантиметров.";
// Работает, ключи, взятые в кавычки, работают только с синтаксисом фигурных скобок
echo "Это работает: {$arr['key']}";
// Работает
echo "Это работает: {$arr[3][2]}";
echo "Работает: {$arr[DATA_KEY]}";
// При работе с многомерными массивами массивы внутри строк оборачивают в фигурные скобки
echo "Это работает: {$arr['foo'][2]}";
echo "Работает: {$obj->values[3]->name}";
echo "Работает: {$obj->$staticProp}";
// Не работает, выводит: C:\directory\{fantastic}.txt
echo "C:\directory\{$great}.txt";
// Работает, выводит: C:\directory\fantastic.txt
echo "C:\\directory\\{$great}.txt";
```

- Работа с вводом выводом
- Форматирование строк
- Шаблонизация и интернационализация
