# Anonymous functions and classes

https://www.php.net/functions.anonymous
https://wiki.php.net/rfc/closures
https://www.php.net/manual/ru/language.oop5.anonymous.php

Класс `Closure` связан с псевдотипом `callable`. Также к этому псевдотипу могут относиться:
- Cтроки. Строка с именем функции, строка с квалифицированным именем класса + метод класса `$x = 'Foo::bar'`;
- Массив, где нулевой элемент - квалифицированное имя класса, первый элемент - имя метода `[Foo::class, 'bar']`;
- Объект с определенным магическим методом __invoke()

До PHP 5.3. Также была возможность использовать анонимные функции - метод `create_function()`. На самом деле `create_function()` не создает анонимную функцию, а создает именованную функцию в глобальной области видимости с именем вида “lambda_1” и возвращает ее имя. И, т.к. строки могут относиться к типу callable, это позволяет использовать результат работы функции `create_function()` как callback.

Для создания анонимных функций используется класс `Closure`.
Синтаксис:

```php
$var = 1;

$closure = function() use ($var) {  
    echo $var;  
};  

$var = 2;
$closure(); //1
```

Чтобы передать в анонимную функцию значения из родительского скоупа, используется ключевое слово `use`. Тут нужно обратить внимание на то, что при объявлении анонимной функции, переменные из `use` будут скопированы и их дальнейшее изменение не повлияет на значение внутри анонимной функции.
В случае с классами значение будет передано по ссылке.

Однако, можно передавать ссылку на переменную:
```php
$var = 1;

$closure = function() use (&$var) {
    echo $var;
};

$var = 2;
$closure(); //2
```

Для рекурсивного вызова нужно передать в `use` ссылку на саму себя (по значению передать не получится, ошибка несуществующей переменной):
```php
$factorial = function( $n ) use ( &$factorial ) {
    if( $n == 1 ) return 1;
    return $factorial( $n - 1 ) * $n;
};
print $factorial( 5 );
```

Внутри анонимной функции по умолчанию доступен объект `$this`, если функция находится внутри класса или биндится к нему впоследствии. Внутри функции будет доступен вызов приватных членов класса:

```php
class Foo
{
    private function bar(): void
    {
        echo 'private bar';
    }

    public function biz(): void
    {
        $closure = function() {
            $this->bar();
        };

        $closure();
    }
}

$foo = new Foo();

$closure = function() {
    $this->bar();
};

$closure->call($foo); //private bar
$foo->biz(); //private bar
```

При использовании `$this` вне контекста класса будет выброшено исключение.
Нельзя биндить анонимные функции к встроенным классам.

Для предотвращения связывания анонимной функции с `$this` внутри класса, можно использовать ключевое слово `static` при объявлении анонимной функции.

В php 7.4 появились **стрелочные функции** - короткая запись анонимных функций.
Они работают так же как обычные анонимные функции, но при этом могут автоматически захватывать переменные по значению из родительского скоупа без использвания `use`.

```php
$y = 1;

$fn1 = fn($x) => $x + $y;
// эквивалентно использованию $y по значению:
$fn2 = function ($x) use ($y) {
    return $x + $y;
};
```

В php 7.? были введены анонимные классы

```php
interface Logger {
  public function log($message);
}

$logger = new class implements Logger {
  public function log($message) {
    echo $message;
  }
};
```
