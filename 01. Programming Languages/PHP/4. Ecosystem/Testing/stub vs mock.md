# Stub vs Mock

Различия между стабами (stubs) и моками (mocks) в тестировании.

## Стаб (Stub)

Стаб используется для предоставления предопределенного ответа на вызовы методов. Основная цель — заменить реальные зависимости и предоставить контролируемую среду для тестов.

### Характеристики

- Предоставляет предопределенные данные
- Не проверяет вызовы методов
- Не проверяет параметры методов
- Фокус на результатах, а не на взаимодействии

### Пример

```php
<?php
use PHPUnit\Framework\TestCase;

class UserServiceTest extends TestCase
{
    public function testGetUserName(): void
    {
        // Создаем стаб для UserRepository
        $userRepositoryStub = $this->createStub(UserRepository::class);
        
        // Настраиваем метод find на возврат заранее определенного результата
        $userRepositoryStub->method('find')
            ->willReturn(new User('John Doe'));
        
        // Тестируем UserService с использованием стаба
        $userService = new UserService($userRepositoryStub);
        $this->assertEquals('John Doe', $userService->getUserName(1));
    }
}
```

## Мок (Mock)

Мок используется для проверки взаимодействия между тестируемым кодом и его зависимостями. Моки устанавливают ожидания на вызовы методов, их количество и параметры.

### Характеристики

- Проверяет вызовы методов
- Проверяет количество вызовов
- Проверяет параметры вызовов
- Фокус на взаимодействии, а не только на результатах

### Пример

```php
<?php
use PHPUnit\Framework\TestCase;

class UserServiceTest extends TestCase
{
    public function testGetUserName(): void
    {
        // Создаем мок для UserRepository
        $userRepositoryMock = $this->createMock(UserRepository::class);
        
        // Настраиваем ожидания для метода find
        $userRepositoryMock->expects($this->once())
            ->method('find')
            ->with($this->equalTo(1))
            ->willReturn(new User('John Doe'));
        
        // Тестируем UserService с использованием мока
        $userService = new UserService($userRepositoryMock);
        $this->assertEquals('John Doe', $userService->getUserName(1));
        
        // Мок автоматически проверяет, что метод find был вызван ровно один раз с параметром 1
    }
}
```

## Основные различия

### 1. Цель

- **Стаб**: Предоставление предопределенных ответов, фокусировка на результатах методов
- **Мок**: Проверка взаимодействий между объектами, установка ожиданий на вызовы методов и их параметры

### 2. Проверка

- **Стаб**: Не проверяет, как и когда вызываются методы
- **Мок**: Проверяет вызовы методов, их количество и параметры

### 3. Использование

- **Стаб**: Используется, когда нужно подставить фиксированные данные и не важно, как они были получены
- **Мок**: Используется, когда нужно проверить, что определенные методы были вызваны определенное количество раз с определенными параметрами

## Когда использовать

### Используйте стаб, когда:

- Нужно только подставить данные
- Не важно, как часто вызывается метод
- Не важно, с какими параметрами вызывается метод
- Тестируете результат работы метода, а не взаимодействие

### Используйте мок, когда:

- Нужно проверить, что метод был вызван
- Нужно проверить количество вызовов
- Нужно проверить параметры вызова
- Тестируете взаимодействие между объектами

## Резюме

- **Стаб** возвращает заранее определенные данные и не проверяет вызовы методов
- **Мок** устанавливает ожидания на вызовы методов и проверяет их выполнение
