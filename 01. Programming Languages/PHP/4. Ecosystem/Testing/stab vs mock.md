В контексте тестирования программного обеспечения, особенно при использовании тестирования на основе объектов (например, в PHP с PHPUnit), термины "стаб" (stub) и "мок" (mock) относятся к созданию поддельных объектов или методов для имитации поведения реальных объектов. Они используются для изоляции тестируемого кода и проверки его поведения. Вот основные различия между стопами и мока:

Стаб (Stub)

✅Используется для предоставления предопределенного ответа на вызовы методов, которые не влияют на проверку поведения тестируемого кода. Основная цель — заменить реальные зависимости и предоставить контролируемую среду для тестов.
✅Позволяют задать фиктивные данные, которые будут возвращены методами объекта.
✅Они не следят за вызовами методов или их параметрами.

```php
class UserServiceTest extends TestCase {
    public function testGetUserName() {
        // Создаем стаб для UserRepository
        $userRepositoryStub = $this->createStub(UserRepository::class);
        
        // Настраиваем метод find на возврат заранее определенного результата
        $userRepositoryStub->method('find')
                           ->willReturn(new User('John Doe'));
        
        // Тестируем UserService с использованием стаба
        $userService = new UserService($userRepositoryStub);
        $this->assertEquals('John Doe', $userService->getUserName(1));
    }
}
```

Мок (Mock)

✅Используется для проверки взаимодействия между тестируемым кодом и его зависимостями. Моки могут устанавливать ожидания на вызовы методов, их количество и параметры, а также проверять, что эти ожидания были выполнены.
✅Следят за вызовами методов, позволяют устанавливать ожидания и проверять, что методы были вызваны определенное количество раз с определенными параметрами.

```php
class UserServiceTest extends TestCase {
    public function testGetUserName() {
        // Создаем мок для UserRepository
        $userRepositoryMock = $this->createMock(UserRepository::class);
        
        // Настраиваем ожидания для метода find
        $userRepositoryMock->expects($this->once())
                           ->method('find')
                           ->with($this->equalTo(1))
                           ->willReturn(new User('John Doe'));
        
        // Тестируем UserService с использованием мока
        $userService = new UserService($userRepositoryMock);
        $this->assertEquals('John Doe', $userService->getUserName(1));
    }
}
```

Основные различия

1️⃣Цель:
✅Стаб: Предоставление предопределенных ответов, фокусировка на результатах методов.
✅Мок: Проверка взаимодействий между объектами, установка ожиданий на вызовы методов и их параметры.

2️⃣Проверка:
✅Стаб: Не проверяет, как и когда вызываются методы.
✅Мок: Проверяет вызовы методов, их количество и параметры.

3️⃣Использование:
✅Стаб: Используется, когда нужно подставить фиксированные данные и не важно, как они были получены.
✅Мок: Используется, когда нужно проверить, что определенные методы были вызваны определенное количество раз с определенными параметрами.

✅Стаб возвращает заранее определенные данные и не проверяет вызовы методов.
✅Мок устанавливает ожидания на вызовы методов и проверяет их выполнение.
