# PHP 7.4

В PHP 7.4, выпущенной 28 ноября 2019 года, было введено множество новых функций и улучшений, которые повышают производительность и удобство программирования. Вот некоторые из ключевых изменений:

## Стрелочные функции (Arrow Functions)
Стрелочные функции, или короткие замыкания, позволяют писать компактные анонимные функции с использованием синтаксиса fn.

```php
      $factor = 10;
   $multiplier = fn($x) => $x * $factor;
   echo $multiplier(5); // Выведет 50
```

## Typed Properties (Типизированные свойства)
Теперь можно объявлять типы для свойств классов.

```php
      class User {
       public string $name;
       public int $age;
   }

   $user = new User();
   $user->name = "John";
   $user->age = 30;
```

## Null Coalescing Assignment Operator (Оператор присваивания слияния с null)
Новый оператор ??= позволяет присвоить значение переменной, если оно не установлено (null).

```php
$data['username'] ??= 'guest';
```

## Unpacking Inside Arrays (Распаковка массивов)
Распаковка массивов с помощью оператора ... теперь поддерживается и внутри массивов.

```php
      $parts = ['apple', 'banana'];
   $fruits = ['orange', ...$parts, 'grape'];
   // $fruits будет ['orange', 'apple', 'banana', 'grape']
```

## Weak References (Слабые ссылки)
Слабые ссылки позволяют удерживать ссылку на объект, не предотвращая его уничтожение сборщиком мусора.

```php
      $obj = new stdClass();
   $weakRef = WeakReference::create($obj);
   unset($obj);
   var_dump($weakRef->get()); // Выведет NULL
```

## Covariant Returns and Contravariant Parameters (Ковариантные возвращаемые значения и контравариантные параметры)
PHP теперь поддерживает ковариантные типы возвращаемых значений и контравариантные типы параметров.

```php
      class Animal {}
   class Dog extends Animal {}

   interface Factory {
       public function make(): Animal;
   }

   class DogFactory implements Factory {
       public function make(): Dog {
           return new Dog();
       }
   }
```

## Preloading (Предварительная загрузка)
Новый механизм предварительной загрузки позволяет загружать классы и функции в опкод кэш перед обработкой запросов, что улучшает производительность.

```php
      // preloader.php
   opcache_compile_file('/path/to/project/vendor/autoload.php');
   
```
В php.ini:
```ini
opcache.preload=/path/to/preloader.php
```

## Custom Object Serialization (Пользовательская сериализация объектов)
Новый интерфейс __serialize и __unserialize позволяет настраивать процесс сериализации и десериализации объектов.

```php
      class User {
       private $name;
       private $email;

       public function __serialize(): array {
           return [
               'name' => $this->name,
               'email' => $this->email,
           ];
       }

       public function __unserialize(array $data): void {
           $this->name = $data['name'];
           $this->email = $data['email'];
       }
   }
```

# Депрекреции и удаление

## Депрекреция динамических методов
Объявление методов классов на лету стало депрекрецированным и будет удалено в будущем.

## Удаление устаревших расширений
Устаревшие расширения, такие как ext/ereg, были удалены.


# Улучшения производительности

## Оптимизация компиляции и выполнения кода
Внесены изменения в движок Zend Engine, что улучшает общую производительность PHP 7.4 по сравнению с предыдущими версиями.
