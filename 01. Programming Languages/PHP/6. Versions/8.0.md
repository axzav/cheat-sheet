В PHP 8 были введены важные изменения в приведении типов, которые влияют на поведение и строгую типизацию. Вот основные нововведения и их последствия:

Основные изменения

1️⃣Строгая типизация (`strict_types`):
✅В PHP 7 можно было включить строгую типизацию на уровне файла с помощью директивы declare(strict_types=1);. Это требование сохраняется и в PHP 8, но типизация стала еще строже в некоторых аспектах.

2️⃣Улучшенная проверка типов при передаче аргументов и возврате значений:
✅Типы параметров и возвращаемых значений функций проверяются более строго. Если значение не соответствует указанному типу, будет выброшено исключение TypeError.

3️⃣Сопоставление с новыми типами:
✅Union Types: Добавляет поддержку объединенных типов (union types), которые позволяют указать несколько типов для одного параметра или возвращаемого значения.

```php
      function foo(int|float $number): int|float {
       return $number;
   }
   
```

4️⃣Mixed type:
✅Тип теперь используется для обозначения переменной, которая может содержать значение любого типа. Этот тип включает в себя все возможные типы, включая null.

```php
      function bar(mixed $value): mixed {
       return $value;
   }
```

5️⃣Строгая проверка при приведении строк к числам:
✅Изменил поведение при приведении строк к числам. Теперь строки, которые не могут быть интерпретированы как корректные числа, не будут автоматически приводиться к 0, и будет выбрасываться предупреждение.

```php
      $result = (int) "123abc"; // В PHP 8 это вызовет предупреждение, так как "123abc" не является корректным числом.
```

6️⃣Строгая проверка при приведении `null`:
✅Также вводит более строгую проверку для приведения null. Например, вызов функции с параметром, который должен быть объектом, но которому передается null, вызовет ошибку.

Union Types
```php
function processNumber(int|float $number): int|float {
    return $number * 2;
}

echo processNumber(5);    // 10
echo processNumber(5.5);  // 11.0
```

Строгая проверка строк к числам
```php
$number = "123abc";
$result = (int) $number; // В PHP 8 это вызовет предупреждение
```

Использование mixed типа
```php
function getValue(mixed $input): mixed {
    if (is_array($input)) {
        return $input[0];
    } else {
        return $input;
    }
}

echo getValue([1, 2, 3]); // 1
echo getValue("string");  // string
```

В PHP 8 типизация стала строже: введены объединенные типы (union types), тип mixed, и улучшена проверка типов. Приведение строк к числам и передача null теперь проверяются тщательнее.
