# Что нового в версиях PHP
http://php.net/manual/ru/appendices.php
https://www.clariontech.com/blog/exploration-of-php-version-history-from-php/fi-to-php-7.3

Personal Home Page Tools, version 1.0.
Первый релиз PHP состоялся в 1995 году

PHP 5.3 (06.2009):
- Пространства имен
- Замыкания (анонимные функции)
- Магический метод `__invoke()` - позволяет вызывать класс как функцию
- Позднее статическое связывание
- Goto

PHP 5.4 (03.2012):
- Трейты
- Короткий синтаксис массивов
- Разыменовывание массивов, которые возвращаются функцией: `foo()[0]`
- Доступ к членам объекта при создании экземпляра класса: (new Foo())->setField(1)
- Введение псевдотипа callable

PHP 5.5 (06.2013):
- Генераторы
- Добавлен блок finally для конструкции try catch
- Добавлено ключевое слово ::class для разрешения полного имени класса

PHP 5.6 (08.2014):
- Константные выражения
- Возможность передавать переменное количество аргументов в функции с помощью оператора … вместо использования func_get_args()
- Распаковка массива в аргументы функции с помощью оператора ...

PHP 7.0 (12.2015):
- В основу этой версии вошли изменения ветки PHPNG (next generation)
- Ошибки FATAL ERRORS заменены на exceptions
- Type hinting для скалярных типов: bool, float, int, string. Type hinting для имени класса и self был введен в 5.0, для array в 5.1, для callable в 5.4. Есть 2 опции для type hinting - coercive (default) и strict. В случае принудительного режима типизации, переданный аргумент будет скастован к указанному в аргументе типу. В случае режима строгой типизации, если будут передан аргумент другого типа, то будет выброшено исключение типа TypeError
- Объявление типов возвращаемых значений. Такими типами могут быть указаны те же типы, что и в type hinting
- Анонимные классы
- Выражение return в генераторе со значением

PHP 7.1 (12.2016):
- Nullable types в аргументах функций и возвращаемых значениях
- Область видимость констант класса
- Тип void для возвращаемого значения функции
- Псевдотип iterable
- Поддержка отрицательных смещений для строк

PHP 7.2 (11.2017):
- Тип object может быть использован в передаваемых аргументах и в возвращаемых значениях
- Перегрузка абстрактных методов а абстрактных классах, которые наследуют другой абстрактный класс

PHP 7.3 (12.2018):
- Некоторые фатальные ошибки компиляции заменены на исключение CompileError

PHP 7.4 (11.2019)
- Типизированные свойства классов (`public int $id;`)
- Стрелочные функции
- Ограниченная ковариация возвращаемого типа и контравариантность типа аргумента (?)
- Присваивающий оператор объединения с null  - `$array['key'] ??= computeDefault();`
- WeakReference (слабые ссылки). Зачем нужны?

PHP 8.0 (11.2020)
- Именованные аргументы
- Атрибуты
- Определение свойств в конструкторе
- Объединение типов (?)
- Выражение match (наподобие switch)
- nullsafe оператор - `?->`
- Тип mixed
- JIT-компиляция

PHP 8.1 (11.2021)
- Перечисления (enums)
- Fibers (файберы, что это?)
- Пересечение типов (?)
- Тип возвращаемого значения `never`
- Свойство `readonly`
- Final константы

PHP 8.2 (12.2022)
- Readonly classes
- unions in arguments
- true, false return types
- trait constants
- deprecate dynamic properties
