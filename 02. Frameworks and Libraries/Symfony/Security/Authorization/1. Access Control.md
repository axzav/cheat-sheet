# Access Control

Есть 2 способа включить авторизацию для роутов - `access_control` в `security.yaml` и напрямую в контроллере.
В случае, если доступ не разрешен будет выброшено исключение `Symfony\Component\Security\Core\Exception\AccessDeniedException`.

## access_control

Только один паттерн будет использован для запроса. `Symfony` будет проходить по паттернам сверху вниз пока не найдет подходящий.

```yaml
# config/packages/security.yaml
security:

    access_control:
        # allow unauthenticated users to access the login form
        - { path: '^/admin/login', roles: PUBLIC_ACCESS }

        # require ROLE_SUPER_ADMIN for /admin/users*
        - { path: '^/admin/users', roles: ROLE_SUPER_ADMIN }
        
        # require ROLE_ADMIN for /admin*
        - { path: '^/admin', roles: ROLE_ADMIN }

        # or require ROLE_ADMIN or IS_AUTHENTICATED_FULLY for /admin*
        - { path: '^/admin', roles: [IS_AUTHENTICATED_FULLY, ROLE_ADMIN] }

        # the 'path' value can be any valid regular expression
        # (this one will match URLs like /api/post/7298 and /api/comment/528491)
        - { path: ^/api/(post|comment)/\d+$, roles: ROLE_USER }
```

## Controller

Другой способ - указывать security атрибуты или вызывать методы в контроллере для ограничения доступа.
Это более гибкий способ и позволяет передавать данные в `Voter`.

```php
use App\Entity\Post;

use Symfony\Component\Security\Http\Attribute\IsGranted;
use Symfony\Component\Security\Http\Attribute\CurrentUser;
use Symfony\Component\Security\Core\User\UserInterface;

// Можно установить deny на весь класс контроллера или на конкретный метод
#[IsGranted('ROLE_ADMIN')]
class PostController extends AbstractController
{
    // Можно установить кастомное сообщение и статус код
    #[IsGranted('ROLE_SUPER_ADMIN', message: 'You are not allowed to access the admin dashboard.', statusCode: 423)]
    public function adminDashboard(): Response
    {
        // ...
    }

    // Можно установить ограничение на конкретные HTTP методы
    #[IsGranted('ROLE_SUPER_ADMIN', methods: ['GET', 'PUT'])]
    public function action(): Response
    {
        // ...
    }

    #[Route('/posts/{id}/edit', name: 'post_edit')]
    // Передать в Voter аргумент метода
    #[IsGranted('POST_EDIT', 'post')]
    public function edit(Post $post): Response
    {
        // ...
    }

    // Можно проверять прямо в коде
    public function view(Post $post): Response
    {
        $isGranted = $this->isGranted('POST_VIEW', $post);

        // Сразу бросить исключение
        $this->denyAccessUnlessGranted('ROLE_ADMIN');
        $this->denyAccessUnlessGranted('IS_AUTHENTICATED');
    }

    // Можно передать аргумент с атрибутом #[CurrentUser], тогда это будет эквивалентно IS_AUTHENTICATED_FULLY
    // Можно использовать UserInterface или конкретные классы пользователей
    // Можно сделать аргумент nullable, тогда аутентификация будет необязательна
    public function view(Post $post, #[CurrentUser] ?UserInterface $user): Response
    {
        // ...
    }
}
```

## Security service

При необходимости можно заинжектить `Security` сервис в любой другой:

```php
    use Symfony\Bundle\SecurityBundle\Security;

    class SomeManager
    {
        public function __construct(
            private Security $security,
        ) {
        }

        public function someAction(): void
        {
            $salesData = [];

            if ($this->security->isGranted('ROLE_ADMIN')) {
                // oops
            }
        }
    }
```
