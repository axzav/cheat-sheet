# Voters

Путь принятия решения по доступу к ресурсу:
```text
Controller
   ↓
Security Expression
   ↓
AuthorizationChecker
   ↓
AccessDecisionManager
   ↓
Voters
```

**Security Expression**
Для ограничения доступа к контроллеру указываются аттрибуты Security с ролями и permission attribute
```php
#[Security("is_granted('ROLE_SUPER_ADMIN') or is_granted('ORGANIZATION_MEMBERSHIP_MANAGEMENT', accountId)")]
```


**AuthorizationChecker**
`Security Expressions` разбираются, и для каждого из них по очереди запускается `AuthorizationChecker`
```php
use Symfony\Component\Security\Core\Authorization\AccessDecisionManagerInterface;

AuthorizationCheckerInterface::isGranted('ORGANIZATION_MEMBERSHIP_MANAGEMENT', $accountId);

$this->isGranted('ORGANIZATION_MEMBERSHIP_MANAGEMENT', $accountId); # Или напрямую в контроллере
```

**AccessDecisionManager**
`AccessDecisionManager` проходит по **всем** `Voter` и на основе выбранной стратегии (`AffirmativeStrategy` по умолчанию) возвращает результат - доступ разрешен или нет.
```php
use Symfony\Component\Security\Core\Authorization\AccessDecisionManagerInterface;

AccessDecisionManagerInterface::decide($token, ['ORGANIZATION_MEMBERSHIP_MANAGEMENT'], $accountId);
```

В больших системах могут быть десятки `Voter` и это может сильно влиять на производительность, особенно если `Voter::supports()` написан плохо.
Для предотвращения этой ситуации можно применить паттерн **Policy Voters**.

**Voter**
В симфони есть предопределенный набор воутеров которые срабатывают по умолчанию - `Symfony\Component\Security\Core\Authorization\Voter`
Если нужно зарегистрировать свой `Voter` то нужно создать класс, который наследует symfony `Voter` или реализует `Symfony\Component\Security\Core\Authorization\Voter\VoterInterface`
```php
use Symfony\Component\Security\Core\Authorization\Voter\Voter;

class OrganizationVoter extends Voter
{
    protected function supports($attribute, $subject): bool
    {
        return $attribute === 'ORGANIZATION_MEMBERSHIP_MANAGEMENT';
    }

    protected function voteOnAttribute($attribute, $subject, TokenInterface $token): bool
    {
        $accountId = $subject;
        $user = $token->getUser();

        return $this->service->canManageMembership($user, $accountId);
    }
}
```
