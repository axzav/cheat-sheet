# Recursion

Решение задачи более мелкими экземплярами этой же задачи.

Чтобы рекурсия работала, должны соблюдаться 2 условия:
- Наличие базового случая - когда вычисления производятся непосредственно
- Рекурсивный вызов должен быть меньшим экземпляром решения задачи, который приведет в конечном счете к базовому случаю
