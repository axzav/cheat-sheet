# Linked list

Односвязный список (или просто связный список) — это базовая структура данных, состоящая из узлов, каждый из которых содержит данные и указатель (ссылку) на следующий узел в последовательности. Эта структура данных используется для хранения коллекции элементов и отличается от массивов тем, что элементы не обязательно расположены в последовательной памяти.

Структура

1️⃣Узлы (Nodes):
Каждый узел в односвязном списке состоит из двух частей:
✅Данные: Значение, которое хранится в узле (например, целое число, строка или объект).
✅Указатель: Ссылка на следующий узел в списке.

2️⃣Голова (Head):
Указатель на первый узел списка. Если список пуст, голова указывает на null.

3️⃣Хвост (Tail):
Последний узел списка, его указатель на следующий узел равен null.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class SinglyLinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:
            last_node = last_node.next
        last_node.next = new_node

    def print_list(self):
        current_node = self.head
        while current_node:
            print(current_node.data, end=" -> ")
            current_node = current_node.next
        print("None")

# Использование односвязного списка
sll = SinglyLinkedList()
sll.append(1)
sll.append(2)
sll.append(3)
sll.print_list()  # Выведет: 1 -> 2 -> 3 -> None
```

Основные операции

1️⃣Вставка (Insertion):
✅В начало списка: Вставка нового узла в начало списка.
✅В конец списка: Вставка нового узла в конец списка (как показано в примере выше).
✅В середину списка: Вставка нового узла после определенного узла.

2️⃣Удаление (Deletion):
✅Удаление первого узла: Изменение указателя головы на второй узел.
✅Удаление последнего узла: Поиск предпоследнего узла и изменение его указателя на null.
✅Удаление узла в середине: Изменение указателя предыдущего узла на узел, следующий за удаляемым.

3️⃣Поиск (Search):
Поиск узла с определенным значением, начиная с головы и проходя через каждый узел до нахождения нужного или достижения конца списка.

4️⃣Обход (Traversal):
Прохождение через все узлы списка, обычно для выполнения какой-либо операции, такой как вывод данных всех узлов (как в методе print_list).

Преимущества

1️⃣Динамическое управление памятью: Узлы могут быть добавлены и удалены без перераспределения всей структуры, что делает односвязные списки гибкими и экономными с точки зрения использования памяти.
2️⃣Простота вставки и удаления: Вставка и удаление узлов, особенно в начале списка, происходит за константное время O(1).

Недостатки

1️⃣Сложность поиска: Поиск элемента в списке требует обхода всех узлов, что занимает линейное время O(n).
2️⃣Отсутствие прямого доступа: Нет возможности прямого доступа к элементу по индексу, как в массиве; необходимо пройти по всем предыдущим узлам, чтобы добраться до нужного.

Односвязный список — это структура данных, состоящая из узлов, каждый из которых содержит данные и указатель на следующий узел. Он обеспечивает гибкое управление памятью и позволяет эффективно выполнять операции вставки и удаления. Однако поиск и доступ к элементам требуют линейного времени, что может быть неэффективно для больших списков.
