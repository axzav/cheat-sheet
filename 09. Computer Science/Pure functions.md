Чистые функции (pure functions) — это функции, которые обладают следующими ключевыми свойствами:

1️⃣Отсутствие побочных эффектов:
✅Чистая функция не изменяет состояние программы или взаимодействует с внешними системами (такими как файлы, базы данных, глобальные переменные и т.д.). Все вычисления происходят только внутри функции и не влияют на что-либо за её пределами.

2️⃣Детерминированность (предсказуемость):
✅Чистая функция всегда возвращает одно и то же значение для одного и того же набора входных данных. Это означает, что результат функции зависит только от её входных параметров.

Примеры чистых функций
```python
def add(a, b):
    return a + b
```

В данном примере функция add является чистой, потому что она:
✅Всегда возвращает одно и то же значение для одного и того же набора входных параметров.
✅Не изменяет состояние внешних переменных или объектов.

```python
function multiply(x, y) {
    return x * y;
}
```

Функция multiply также является чистой, потому что:
✅Результат зависит только от значений параметров x и y.
✅Нет побочных эффектов — функция не изменяет внешнее состояние.

Примеры нечистых функций
```python
def add_to_list(value, my_list):
    my_list.append(value)
    return my_list
```

Функция add_to_list не является чистой, потому что:
✅Она изменяет состояние переданного ей списка (побочный эффект).
✅Результат может зависеть от состояния входного списка, который может быть разным при разных вызовах функции.

```python
let counter = 0;
function increment() {
    counter += 1;
    return counter;
}
```

Функция increment не является чистой, потому что:
✅Она изменяет значение глобальной переменной counter (побочный эффект).
✅Результат зависит от внешней переменной counter, что нарушает детерминированность.

Преимущества

1️⃣Легкость тестирования:
✅Чистые функции легко тестировать, потому что они всегда возвращают предсказуемые результаты для одинаковых входных данных.
   
2️⃣Повышенная читаемость и поддерживаемость:
✅Код с чистыми функциями проще понимать, потому что можно не беспокоиться о скрытых изменениях состояния.
   
3️⃣Безопасная параллелизация:
✅Чистые функции можно безопасно выполнять в параллельных или многопоточных средах, так как они не взаимодействуют с общими состояниями.

4️⃣Мемоизация:
✅Чистые функции можно легко оптимизировать с помощью мемоизации (кэширования результатов функций), так как результат всегда детерминирован.

Чистые функции — это функции, которые не имеют побочных эффектов и всегда возвращают одно и то же значение для одного и того же набора входных параметров. Это делает их предсказуемыми, легко тестируемыми и безопасными для параллельного выполнения.
