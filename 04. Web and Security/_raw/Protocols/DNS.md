# DNS (Domain Name System)

Протокол прикладного уровня который позволяет связать IP-адрес и доменное имя.
Одному доменному имени может соответствовать несколько IP-адресов. Работает поверх UDP.

## Распределенная система DNS

**Url:**
www.google.com.
. - коренной домен
.com - домен верхнего имени
.google - домен второго уровня
www - имя компьютера

Структура URL и DNS древообразная. Домен разделен на доменные зоны (корневой домен, ru, yandex, etc). Каждая зона содержит в себе записи о всех входящих подзонах и хостах.
Одну зону могут обслуживать несколько серверов DNS. К корневым и доменам верхнего уровня будет поступать очень много запросов.

## Схема работы DNS

DNS сервера могут работать в двух режимах:
- **Итеративный**. Если сервер знает адрес хоста, то он возвращает адрес, если нет, то возвращает адрес DNS сервера у которого есть информация
- **Рекурсивный**. Сервер сам выполняет запросы к другим DNS серверам пока не получит нужный IP-адрес хоста 

**DNS Resolver** - тип DNS сервера к которому идут запросы от клиентов. Этот сервер работает в **рекурсивном режиме**. Обычно он предоставляется провайдером и клиент получает его адрес по DHCP. Сервера DNS которые хранят записи зон работают в **итеративном** режиме.

Ответ DNS сервера может быть двух типов:
- **Авторитетный** - получен он сервера обслуживающего доменную зону
- **Неавторитетный** - получен из кеша другого сервера


Если клиент DNS хочет получить IP-адрес сервера **maps.yandex.ru**., то схема запросов будет выглядеть следующим образом:

- Клиент делает запрос на **DNS Resolver**.
- Запрос на **корневой домен**. Он отвечает, что у него нет информации о хосте, но она должна быть у зоны **ru**
- Запрос на зону **.ru.**. Он отвечает, что у него нет информации о хосте, но она должна быть у зоны **yandex**
- Запрос на зону **yandex.ru.**. Этот DNS сервер знает адрес хоста и возвращает IP-адрес

## Типы DNS записей

- A - запись класса A указывает на связь IP адреса и доменного имени
- AAAA - то же самое, что A, только для IPv6
- CNAME - определяет псевдоним для записи класса A (можно привязать одному IP-адресу несколько доменных имен)
- NS (Name server) - указывает адреса DNS-серверов отвечающих за зону. Задаются на серверах более высого уровня (например для **yandex.ru** запись будет создана на **.ru** DNS-сервере)
