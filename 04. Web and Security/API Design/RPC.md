# RPC (Remote Procedure Call)

**RPC** (Remote Procedure Call) - тип API в котором взаимодействие клиента и сервера выполнено в виде вызова процедур на стороне сервера. При этом некоторые протоколы позволяют передавать потоковые данные (gRPC), возможно двухстороннее взаимодействие, т.е. сервер может отправлять данные клиенту (gRPC, WebSocket).

Основные стандарты:
- SOAP - сложный (XML, WSDL), сейчас мало используется
- JSON-RPC
- gRPC
